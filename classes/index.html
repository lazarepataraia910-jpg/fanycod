👩‍🏫 კლასები

ასწავლე პროგრამირება მთელ კლასს

შექმენი კლასი, მოსწავლეებს უთხარი კოდი და ნახე, ვინ რამდენი გაიარა და სად შეჩერდა. ცოცხალ გაკვეთილზე მოსწავლეები შენს დაფას რეალურ დროში ხედავენ.

კლასის გახსნა ▶

რა არის აქ

🏫 კლასი ერთ წუთში

კლასის სახელი → 6-ასოიანი კოდი. მოსწავლეები მას „კლასში“ წერენ და შემოდიან.

📊 პროგრესი

თითოეული მოსწავლის XP, გავლილი ლეველები, ვარსკვლავები, ენები და სად შეჩერდა.

🔴 ცოცხალი გაკვეთილი

წერ და უშვებ კოდს — მოსწავლეები ხედავენ შენს ფაილებს და შედეგს, გვერდით საკუთარი დაფით.

📁 ფაილები გაკვეთილზე

HTML, CSS და JS ცალკე ფაილებად; მოსწავლე ერთი ღილაკით აკოპირებს შენს კოდს თავის დაფაზე.

🏆 კვირის რეიტინგი

მოსწავლეები ხედავენ კლასის კვირის რეიტინგს — მხოლოდ სახელს და XP-ს.

როგორ დავიწყო

  1. შექმენი ანგარიში CodeQuest-ში.
  2. გახსენი „კლასი“ → „მასწავლებლისთვის“ და შექმენი კლასი.
  3. მოსწავლეებს უთხარი კლასის კოდი.
  4. დააჭირე „გაკვეთილის დაწყება“ და ასწავლე ცოცხლად.

ხშირი კითხვები

რა სჭირდება?

ანგარიში და CodeQuest Pro — მასწავლებელსაც და მოსწავლეებსაც.

მოსწავლეების რა მონაცემებს ვხედავ?

სახელს, XP-ს, გავლილ ლეველებს, ვარსკვლავებს და ენებს. ელფოსტა და პაროლი არ ჩანს.
