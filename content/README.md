# სკოლის კონტენტი: როგორ დავამატოთ თავი

საიტის კოდს ხელი არ ეხება. გვერდებს, მენიუს, ძებნას და `sitemap.xml`-ს [`school/build.js`](../school/build.js) აწყობს ამ ფაილებიდან (Vercel-ზე ყოველ push-ზე, ლოკალურად: `node school/build.js`).
