## რას ისწავლი

- როგორ იწერება კომენტარი HTML-ში
- სამი სიტუაცია, როცა კომენტარი გეხმარება
- რატომ ჩანს კომენტარი ყველასთვის, ვინც გვერდის კოდს გახსნის

## ტექსტი, რომელიც არ ჩანს

**კომენტარი (comment)** შენიშვნაა კოდში: ბრაუზერი მას კითხულობს, მაგრამ ეკრანზე არ აჩვენებს. HTML-ში კომენტარი `<!--`-ით იწყება და `-->`-ით მთავრდება:

```html
<!-- ეს კომენტარია, ეკრანზე არ ჩანს -->
<p>ეს აბზაცი კი ჩანს.</p>
```

კომენტარი შეიძლება რამდენიმე ხაზზე გაგრძელდეს: ყველაფერი `<!--`-სა და `-->`-ს შორის ერთი კომენტარია, რამდენი ხაზიც არ უნდა იყოს.

JavaScript-ში კომენტარი `//`-ით იწერებოდა. ყოველ ენას თავისი ჩანაწერი აქვს, მაგრამ იდეა ყველგან ერთია: ტექსტი ადამიანებისთვის და არა კომპიუტერისთვის.

## როდის გამოგადგება

**1. ახსნა.** როცა კოდის რაღაც ნაწილი ერთი შეხედვით გაუგებარია, კომენტარი ამბობს, რატომ არის ასე:

```html
<!-- ფორმა სკოლის ღონისძიებაზე რეგისტრაციისთვის; ივნისის ბოლომდე -->
```

**2. ნაწილების მონიშვნა.** გრძელ გვერდზე კომენტარები სარჩევივით მუშაობს და გეხმარება, სწრაფად იპოვო საჭირო ნაწილი:

```html
<!-- ===== მენიუ ===== -->
<!-- ===== მთავარი შინაარსი ===== -->
<!-- ===== ძირი: კონტაქტი ===== -->
```

**3. დროებითი გამორთვა.** თუ გინდა, ნახო, როგორ გამოიყურება გვერდი რაიმე ნაწილის გარეშე, წაშლა არ გჭირდება: ჩასვი ის კომენტარში. მოგვიანებით `<!--` და `-->`-ს წაშლით ნაწილი დაბრუნდება. ეს ხერხი შეცდომის ძებნისასაც გამოგადგება: გამორთე ნაწილ-ნაწილ, სანამ პრობლემური ელემენტი არ გამოჩნდება.

## კომენტარი ყველასთვის ჩანს

კომენტარი ეკრანზე არ ჩანს, მაგრამ **საიდუმლო არ არის**. სერვერი HTML-ს მთლიანად აგზავნის, კომენტარების ჩათვლით, და ნებისმიერს შეუძლია Ctrl+U-თი გვერდის კოდი გახსნას და ყველაფერი წაიკითხოს. ამიტომ კომენტარში არასოდეს ჩაწერო:

- პაროლები, გასაღებები, პირადი მონაცემები;
- შენიშვნები, რომლებიც სხვამ არ უნდა ნახოს, მაგალითად „ეს ფასი დროებითაა, მერე გავაძვირებთ“.

კარგი კომენტარი მოკლეა და ამბობს **რატომ**, და არა **რას**: `<!-- აბზაცი -->` `<p>`-ის წინ არაფერს ამატებს, ეს ისედაც ჩანს.

## ორი ტექნიკური წესი

- **კომენტარი კომენტარში არ ჩაისმის.** პირველი `-->` ხურავს კომენტარს, ამიტომ შიდა კომენტარის დასასრულის შემდეგ დარჩენილი ტექსტი ეკრანზე გამოჩნდება.
- **კომენტარის შიგნით ორი ტირე `--` არ გამოიყენო.** ზოგ ხელსაწყოში ეს შეცდომად ითვლება. ტირეების რიგისთვის ტოლობის ნიშნები ან სხვა სიმბოლოები აირჩიე, როგორც ზემოთ: `=====`.

## სცადე თავად

გაუშვი. მერე გამორთე მეორე აბზაცი კომენტარით, წაუშლელად, და ისევ გაუშვი.

```html run
<!-- ===== ჩემი დღიური ===== -->
<h1>ჩემი დღიური</h1>
<p>ორშაბათი: ვისწავლე HTML კომენტარები.</p>
<p>სამშაბათი: ვისწავლე ჩადგმა.</p>
<!-- ოთხშაბათი ჯერ არ დამდგარა -->
```

## ხშირი შეცდომები

- **დაუხურავი კომენტარი.** თუ `-->` დაგავიწყდა, ყველაფერი, რაც შემდეგ წერია, კომენტარად იქცევა და ეკრანიდან ქრება.
- **საიდუმლო კომენტარში.** HTML კოდს ყველა ხედავს.
- **ზედმეტი კომენტარები.** კომენტარი, რომელიც უბრალოდ იმეორებს კოდს, მხოლოდ ხმაურია.

<Exercise>
ამ გვერდზე: (1) ზემოთ დაამატე კომენტარი, რომელიც ამბობს, ვისთვისაა გვერდი; (2) „დაკარგული ძაღლის“ განცხადება გამორთე კომენტარით, რადგან ძაღლი უკვე იპოვეს; (3) ბოლოს მონიშნე ნაწილი `===== კონტაქტი =====` კომენტარით კონტაქტის აბზაცის წინ.


```html
<h1>ეზოს დაფა</h1>
<p>შაბათს ეზოში ფეხბურთის ტურნირია!</p>

<p>მოგვწერე: dafa@example.com</p>
```

## შეჯამება

- კომენტარი `<!--`-ით იწყება და `-->`-ით მთავრდება. ეკრანზე არ ჩანს.
- გამოიყენე ახსნისთვის, ნაწილების მოსანიშნად და დროებით გამოსართავად.
- კომენტარი ყველასთვის ჩანს გვერდის კოდში: საიდუმლო მასში არ ჩაწერო.
- კომენტარი კომენტარში არ ჩაისმის. კარგი კომენტარი ამბობს, რატომ.
