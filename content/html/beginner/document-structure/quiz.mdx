შეამოწმე, რა დაგამახსოვრდა HTML დოკუმენტის სტრუქტურაზე. თითო კითხვას ერთი სწორი პასუხი აქვს. გასავლელად საჭიროა 70%.

### რას რთავს `<!DOCTYPE html>`?
- [x] სტანდარტების რეჟიმს
- [ ] თავსებადობის რეჟიმს
- [ ] ქართულ ენას
> მის გარეშე ბრაუზერი ძველი გვერდების რეჟიმს რთავს.

### რომელი `lang` მნიშვნელობაა ქართული გვერდისთვის?
- [ ] ge
- [x] ka
- [ ] kartuli
> ka ქართული ენის კოდია.

### რომელი ელემენტია `<head>`-ისა და `<body>`-ის მშობელი?
- [x] html
- [ ] title
- [ ] DOCTYPE
> ორივე html-ის შვილია.

### რომელი იწერება `<body>`-ში?

- [ ] <title>
- [x] <h1>
> body-ში ყველაფერია, რაც ეკრანზე ჩანს.

- [ ] კოდირებისთვის
- [x] ტელეფონზე გვერდის სწორი ზომით საჩვენებლად
- [ ] ჩანართის ხატულისთვის
> მის გარეშე ტელეფონი გვერდს აპატარავებს.

### რამდენი სიმბოლოა კარგი `<title>`-ის დაახლოებითი ზღვარი?
- [ ] 10
- [x] 50–60
- [ ] 300
> გრძელ სათაურს საძიებო სისტემა მოჭრის.

### `<p>ბიტს <em>უყვარს</em> კოდი</p>`-ში რა არის `<em>`?
