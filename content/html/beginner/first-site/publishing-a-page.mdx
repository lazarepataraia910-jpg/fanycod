## რას ისწავლი

- რა არის ჰოსტინგი და დომენი
- რომელი უფასო სერვისებით შეიძლება სტატიკური საიტის გამოქვეყნება
- რა უნდა შეამოწმო გამოქვეყნებამდე და რა არასოდეს უნდა გამოაქვეყნო

## კომპიუტერიდან ინტერნეტში

შენი საიტი ახლა შენს კომპიუტერშია: ფაილს ორჯერ აჭერ და ბრაუზერში იხსნება. მაგრამ მეგობარი მას ვერ ნახავს. ვებგვერდის მუშაობის თავში ისწავლე: გვერდს ბრაუზერი **სერვერს** სთხოვს. ესე იგი, საიტის გამოსაქვეყნებლად მისი ფაილები ისეთ კომპიუტერზე უნდა მოხვდეს, რომელიც დღე და ღამე ჩართულია და მოთხოვნებს პასუხობს.

- **ჰოსტინგი (hosting)** სერვისია, რომელიც შენს ფაილებს სერვერზე ინახავს და ინტერნეტში აჩვენებს.
- **დომენი (domain)** საიტის სახელია: `codequest.space`, `example.com`. ის ცალკე იყიდება, ჩვეულებრივ წელიწადში რამდენიმე ათეულ ლარად. დომენი სავალდებულო არ არის: უფასო ჰოსტინგები საიტს თავიანთ მისამართს აძლევენ.

## სტატიკური საიტი

ჩვენი საიტი მხოლოდ HTML, CSS და სურათებია: სერვერს არაფრის გამოთვლა არ სჭირდება, მხოლოდ ფაილების გაგზავნა. ასეთ საიტს **სტატიკური (static)** ჰქვია. სტატიკური საიტების ჰოსტინგი იაფია ან სულაც უფასო, და რამდენიმე წუთში კეთდება. ეს სკოლაც სტატიკური გვერდებისგან შედგება.

## უფასო სერვისები

რამდენიმე პოპულარული სერვისი, რომელიც სტატიკურ საიტებს უფასოდ აქვეყნებს:

- **GitHub Pages:** ფაილებს ტვირთავ GitHub-ზე, „რეპოზიტორიაში“ (პროექტის საქაღალდეში), და პარამეტრებში რთავ Pages-ს. საიტი ჩნდება მისამართზე `სახელი.github.io/პროექტი`. GitHub ერთდროულად შენი კოდის ისტორიასაც ინახავს: ამას ვერსიების კონტროლის კურსში ისწავლი.
- **Netlify** და **Vercel:** საქაღალდეს „გადაათრევ“ ან GitHub-ს დაუკავშირებ, და ყოველი ცვლილება ავტომატურად ქვეყნდება.

სერვისების ღილაკები და მენიუები დროთა განმავლობაში იცვლება, ამიტომ ნაბიჯ-ნაბიჯ ინსტრუქციას აქ არ მოგცემთ: ყოველ სერვისს თავისი დოკუმენტაცია აქვს „Get started“ განყოფილებაში. მთავარი იდეა ყველგან ერთია: ფაილები სერვერზე, საიტი მისამართზე.

**თუ 13 წელზე ნაკლები ხარ**, ამ სერვისების უმეტესობაზე ანგარიშის შექმნა შენით არ შეიძლება: საიტი მშობელთან ან მასწავლებელთან ერთად გამოაქვეყნე.

## გამოქვეყნებამდე: სია

1. **index.html** საიტის ძირეულ საქაღალდეშია: ის მთავარი გვერდი იქნება.
2. **ყველა ბმული და სურათი მუშაობს**, მისამართები ფარდობითია, სახელები პატარა ლათინური ასოებით.
3. **ვალიდატორი** შეცდომებს აღარ აჩვენებს.
4. **ყოველ გვერდს** აქვს `<title>`, `lang`, `charset` და `viewport`.
5. **გვერდი ტელეფონზეც** კარგად გამოიყურება.

## რა არასოდეს გამოაქვეყნო

ინტერნეტში გამოქვეყნებული ყველასთვის ხელმისაწვდომია, და წაშლის შემდეგაც შეიძლება სადმე დარჩეს: ასლებში, ძებნის სისტემებში, სხვის კომპიუტერში. ამიტომ:

- **პირადი მონაცემები:** სახლის მისამართი, ტელეფონი, სკოლა, ზუსტი დაბადების თარიღი, საკუთარი ფოტოები.
- **სხვისი ფოტოები და მონაცემები** მათი ნებართვის გარეშე.
- **სხვისი ნამუშევარი:** სურათები, ტექსტი, მუსიკა, თუ ავტორს ნებართვა არ მიუცია.
- **პაროლები და გასაღებები** კოდში ან კომენტარებში.

პირადი საიტისთვის საკმარისია სახელი ან მეტსახელი, ჰობი და ნამუშევრები.

## სცადე თავად

ეს გვერდი შენი გამოქვეყნების სიაა. გაუშვი, შემდეგ ყოველ პუნქტზე, რომელიც შენს საიტზე უკვე შეასრულე, `<li>` შეცვალე ისე, რომ დასაწყისში ✔ ეწეროს.

```html run
<h2>გამოქვეყნების სია</h2>
<ul>
  <li>index.html ძირეულ საქაღალდეშია</li>
  <li>ყველა ბმული და სურათი მუშაობს</li>
  <li>ვალიდატორი შეცდომას არ აჩვენებს</li>
  <li>ყოველ გვერდს აქვს title, lang, charset და viewport</li>
  <li>საიტზე პირადი მონაცემები არ არის</li>
</ul>
```

## ხშირი შეცდომები

- **მთავარ გვერდს სხვა სახელი აქვს.** `home.html` ძირში ავტომატურად არ გაიხსნება: მთავარი გვერდი `index.html` უნდა იყოს.
- **აბსოლუტური გზები კომპიუტერიდან.** `C:\Users\...` ინტერნეტში არ იმუშავებს.
- **პირადი ინფორმაცია.** გამოქვეყნებულის „უკან დაბრუნება“ თითქმის შეუძლებელია.

## შეჯამება

- ჰოსტინგი საიტის ფაილებს სერვერზე ინახავს, დომენი საიტის სახელია.
- სტატიკური საიტი (HTML, CSS, სურათები) უფასოდ ქვეყნდება: GitHub Pages, Netlify, Vercel.
- გამოქვეყნებამდე: index.html, მუშა ბმულები, ვალიდატორი, title/lang/charset/viewport, ტელეფონი.
- პირადი მონაცემები, სხვისი ნამუშევარი და პაროლები არასოდეს გამოაქვეყნო.
