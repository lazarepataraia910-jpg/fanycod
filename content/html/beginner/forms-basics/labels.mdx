## რას ისწავლი

- როგორ დააკავშირო წარწერა ველთან `<label>`-ით
- ორი გზა: `for` და `id`, ან ველის `<label>`-ში ჩასმა
- რატომ არ ცვლის `placeholder` წარწერას

## ტექსტი ველის გვერდით საკმარისი არ არის

წინა თავებში ველების წინ უბრალოდ ტექსტს ვწერდით: „სახელი: “ და ველი. ეკრანზე ყველაფერი გასაგებია. მაგრამ ბრაუზერისთვის ეს ტექსტი და ველი ერთმანეთთან არაფრით არის დაკავშირებული: უბრალოდ ერთმანეთის გვერდით დგანან. ეკრანის წამკითხველი, როცა მომხმარებელი ველზე გადავა, მხოლოდ იტყვის „ტექსტის ველი“, და არ ეცოდინება, რა ჩაწეროს.

ამ პრობლემას `<label>` ელემენტი აგვარებს: ის წარწერას ველს **უკავშირებს**.

## for და id

ყველაზე გავრცელებული გზა: ველს მიეცი `id`, წარწერას კი `for` ატრიბუტი იმავე მნიშვნელობით:

```html
<label for="email">ელფოსტა</label>
<input type="email" id="email" name="email">
```

`for="email"` ამბობს: „ეს წარწერა ეკუთვნის ელემენტს, რომლის `id`-ც email-ია“. ახლა სამი რამ ხდება:

1. **ეკრანის წამკითხველი** ველზე გადასვლისას ამბობს: „ელფოსტა, ტექსტის ველი“.
2. **წარწერაზე დაჭერა** კურსორს ველში სვამს. სცადე ქვემოთ!
3. **ხმით მართვის პროგრამები** ველს სახელით პოულობენ: „დააჭირე ელფოსტას“.

`id` და `name` ხშირად ერთნაირია, მაგრამ მათი დანიშნულება სხვადასხვაა: `id` ველს გვერდზე პოულობს (წარწერისთვის, ბმულისთვის, CSS-ისთვის), `name` კი სერვერს ეუბნება მნიშვნელობის სახელს. გახსოვდეს, `id` გვერდზე უნიკალურია.

## ველი წარწერის შიგნით

მეორე გზა: ველი თვითონ `<label>`-ის შიგნით ჩასვი. მაშინ `for` და `id` აღარ გჭირდება:

```html
<label>
  სახელი
  <input type="text" name="name">
</label>
```

ორივე გზა სწორია. პირველი უფრო მოქნილია განლაგებისთვის, მეორე უფრო მოკლეა. ზოგი დეველოპერი ორივეს ერთად იყენებს: ველს წარწერაში სვამს და `for`/`id`-საც წერს, უფრო ძველი დამხმარე პროგრამებისთვის.

## placeholder წარწერა არ არის

გაჩნდება ცდუნება, წარწერა საერთოდ მოაშორო და ველში მხოლოდ `placeholder` დატოვო: ლამაზად და კომპაქტურად გამოიყურება. მაგრამ ეს ცუდი იდეაა:

- აკრეფისას `placeholder` ქრება: გრძელ ფორმაში ადვილად დაგავიწყდება, რომელი ველი რისთვის იყო.
- მისი ღია ნაცრისფერი ტექსტი ბევრისთვის ძნელად იკითხება.
- ეკრანის წამკითხველები მას ყოველთვის არ აცხადებს.

`placeholder` მაგალითისთვისაა („მაგ. nino@example.com“), წარწერა კი ყოველთვის `<label>`-ით.

## სცადე თავად

დააჭირე სიტყვას „ელფოსტა“: კურსორი ველში გადავა. მერე დააჭირე სიტყვას „ტელეფონი“: აქ წარწერა დაკავშირებული არ არის. გაასწორე.

```html run
<form>
  <p>
    <label for="email">ელფოსტა</label>
    <input type="email" id="email" name="email">
  </p>
  <p>
    ტელეფონი
    <input type="tel" name="phone">
  </p>
  <p>
    <label>სახელი <input type="text" name="name"></label>
  </p>
</form>
```

## ხშირი შეცდომები

- **`for` და `id` არ ემთხვევა.** `for="mail"` და `id="email"` ერთმანეთს ვერ იპოვის. მნიშვნელობები ზუსტად ერთნაირი უნდა იყოს.
- **`for`-ში `name`.** `for` ველის `id`-ს ეძებს და არა `name`-ს.
- **ორი ველი ერთი `id`-ით.** წარწერა მხოლოდ პირველს დაუკავშირდება.

## შეჯამება

- `<label>` წარწერას ველს უკავშირებს: წამკითხველი მას აცხადებს, დაჭერით კი ველი აქტიურდება.
- დაკავშირება: `for="x"` წარწერაზე და `id="x"` ველზე, ან ველი `<label>`-ის შიგნით.
- `id` ველს გვერდზე პოულობს, `name` სერვერს მნიშვნელობის სახელს ეუბნება.
- `placeholder` წარწერას არ ცვლის.
