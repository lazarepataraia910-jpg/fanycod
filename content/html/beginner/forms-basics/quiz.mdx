შეამოწმე, რა დაგამახსოვრდა ფორმებზე. თითო კითხვას ერთი სწორი პასუხი აქვს. გასავლელად საჭიროა 70%.

<Quiz>
### რომელი ატრიბუტი ამბობს, სად გაიგზავნება ფორმა?
- [x] action
- [ ] method
- [ ] name
> method ამბობს როგორ, action სად.

### რომელ method-ს გამოიყენებს ძებნის ფორმა?
- [x] get
- [ ] post
- [ ] put
> ძებნა არაფერს ცვლის და მისი მისამართი შეიძლება გააზიარო.

### რა ემართება ველს `name` ატრიბუტის გარეშე?
- [ ] იგზავნება სახელით „field“
- [x] საერთოდ არ იგზავნება
- [ ] ფორმა შეცდომას აჩვენებს
> name-ის გარეშე სერვერი მნიშვნელობას ვერ მიიღებს.

### რომელი ტიპი ამოწმებს, რომ ტექსტში `@` იყოს?
- [ ] text
- [x] email
- [ ] tel
> email ტიპი ელფოსტის ფორმას ამოწმებს.

### რომელი ელემენტი გამოიყენო გრძელი შეტყობინებისთვის?
- [ ] input type="text"
- [x] textarea
- [ ] label
> textarea მრავალხაზიანია.

### როგორ დაუკავშირო `<label for="age">` ველს?
- [x] ველს მიეცი id="age"
- [ ] ველს მიეცი name="age"
- [ ] label-ს მიეცი id="age"
> for ველის id-ს ეძებს.

### რას ამბობს `placeholder`?
- [ ] ის ველის წარწერაა
- [x] ის მინიშნებაა ცარიელ ველში, რომელიც აკრეფისას ქრება
- [ ] ის ველს სავალდებულოს ხდის
> წარწერა ყოველთვის label-ით.

### რას გააკეთებს ფორმაში დაწერილი `<button>` `type`-ის გარეშე?
- [x] ფორმას გააგზავნის
- [ ] არაფერს
- [ ] ფორმას გაასუფთავებს
> ნაგულისხმევი ტიპი submit-ია.

### რომელი ველი გამოიყენო კითხვისთვის „რომელ სკოლაში სწავლობ?“, თუ ვარიანტები ჩამოთვლილია?
- [ ] checkbox
- [x] radio
- [ ] password
> ერთდროულად ერთ სკოლაში სწავლობ.

### რისთვისაა `<legend>`?
- [ ] ფორმის გასაგზავნად
- [x] fieldset-ის ჯგუფის სათაურისთვის, მაგალითად საერთო კითხვისთვის
- [ ] სურათის წარწერისთვის
> legend fieldset-ის პირველი შვილია.
