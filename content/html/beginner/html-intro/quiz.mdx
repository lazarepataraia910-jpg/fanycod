შეამოწმე, რა დაგამახსოვრდა HTML-ის საფუძვლებზე. თითო კითხვას ერთი სწორი პასუხი აქვს. გასავლელად საჭიროა 70%.

<Quiz>
### HTML რა სახის ენაა?
- [ ] პროგრამირების ენა
- [x] მარკირების ენა
- [ ] მონაცემთა ბაზის ენა
> HTML აგებულებას აღწერს და არაფერს ითვლის.

### რომელი ენა პასუხობს ღილაკზე დაჭერისას რაიმე მოქმედებაზე?
- [ ] HTML
- [ ] CSS
- [x] JavaScript
> JavaScript გვერდის ქცევაა.

### რა ხდება, როცა გვერდს სურათი აქვს?
- [x] ბრაუზერი სურათს სერვერს ცალკე მოთხოვნით სთხოვს
- [ ] სურათი HTML ფაილის შიგნით მოდის
- [ ] სურათი DNS-დან მოდის
> ჯერ HTML მოდის, მერე მასში ნახსენები ფაილები.

### რომელი ხაზი უნდა იყოს HTML დოკუმენტის პირველი?
- [x] <!DOCTYPE html>
- [ ] <html>
- [ ] <head>
> DOCTYPE ბრაუზერს ეუბნება, რომ ეს თანამედროვე HTML-ია.

### სად იწერება `<title>`?
- [x] head-ში
- [ ] body-ში
- [ ] html-ის გარეთ
> title გვერდის შესახებ ინფორმაციაა და ჩანართზე ჩანს.

### რას აკეთებს `lang="ka"`?
- [ ] თარგმნის გვერდს ქართულად
- [x] ამბობს, რომ გვერდის ენა ქართულია
- [ ] ქართულ შრიფტს ჩართავს
> ეს ეხმარება ეკრანის წამკითხველებს და საძიებო სისტემებს.

### `<a href="/learn/">სკოლა</a>`-ში რა არის href?
- [ ] ტეგი
- [x] ატრიბუტი
- [ ] შინაარსი
> ატრიბუტი გამხსნელ ტეგშია: სახელი და მნიშვნელობა.

### რომელი ელემენტია ცარიელი?
- [ ] h1
- [x] img
- [ ] p
> img-ს შინაარსი არ აქვს: ყველაფერი ატრიბუტებშია.

### რა უნდა შეამოწმო, თუ ცვლილება ბრაუზერში არ ჩანს?
- [x] შეინახე თუ არა ფაილი და განაახლე თუ არა გვერდი
- [ ] შეცვალე თუ არა ბრაუზერი
- [ ] დახურე თუ არა რედაქტორი
> დაწერე, შეინახე, განაახლე.

### რომელი კლავიში ხსნის დეველოპერის ხელსაწყოებს Chrome-ში?
- [ ] F5
- [x] F12
- [ ] Ctrl+S
