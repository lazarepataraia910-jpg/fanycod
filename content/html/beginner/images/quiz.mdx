შეამოწმე, რა დაგამახსოვრდა სურათებზე. თითო კითხვას ერთი სწორი პასუხი აქვს. გასავლელად საჭიროა 70%.

<Quiz>
### რომელი ჩანაწერი ჩასვამს სურათს სწორად?
- [x] <img src="cat.jpg" alt="ფუმფულა ნაცრისფერი კატა">
- [ ] <img href="cat.jpg">
- [ ] <image src="cat.jpg"></image>
> img ცარიელი ელემენტია, ფაილი src-ში, აღწერა alt-ში.

### სურათის ფაილი `images` საქაღალდეშია, გვერდი კი მის გვერდით. რა წერია src-ში?
- [x] images/cat.jpg
- [ ] ../cat.jpg
- [ ] cat.jpg
> ფარდობითი მისამართი: საქაღალდე/ფაილი.

### ვინ კითხულობს alt ტექსტს ხმამაღლა?
- [ ] ბრაუზერის ხმის ასისტენტი ყოველთვის
- [x] ეკრანის წამკითხველი
- [ ] სერვერი
> ეკრანის წამკითხველით უსინათლო ადამიანები სარგებლობენ.

### რა alt მიეცი გამყოფ დეკორატიულ ხაზს?
- [x] alt=""
- [ ] alt="ხაზი"
- [ ] alt-ს არ დავწერ
> ცარიელი alt ამბობს „გამოტოვე“.

### რომელი ფორმატი არ უჭერს მხარს გამჭვირვალე ფონს?
- [ ] PNG
- [x] JPEG
- [ ] SVG
> JPEG ფონს ყოველთვის ფერით ავსებს.

### რომელი ფორმატია ვექტორული?
- [x] SVG
- [ ] PNG
- [ ] WebP
> ვექტორული სურათი ფორმულებად ინახება.

### ფაილი 800×400-ია. რომელი ზომა ინარჩუნებს პროპორციას?
- [ ] width="400" height="400"
- [x] width="400" height="200"
- [ ] width="200" height="400"
> სიგანე სიმაღლეზე ორჯერ დიდია.

### რატომ არ ამსუბუქებს `width="100"` 5 მეგაბაიტიან ფოტოს?
- [x] ბრაუზერი მაინც მთლიან ფაილს ჩამოტვირთავს და მხოლოდ პატარად აჩვენებს
- [ ] width მხოლოდ სიმაღლეზე მოქმედებს
- [ ] width ფაილს ამსუბუქებს
> ფაილი რედაქტორით უნდა შეამცირო.

### რას აკეთებს `loading="lazy"`?
- [ ] სურათს ბუნდოვნად აჩენს
- [x] სურათს მაშინ ტვირთავს, როცა მასთან ახლოს გადაახვევენ
- [ ] სურათს ორჯერ ტვირთავს
> გრძელ გვერდებზე ტრაფიკს ზოგავს.

### სად იწერება `<figcaption>`?
- [ ] img-ის შიგნით
- [x] figure-ის შიგნით, პირველ ან ბოლო ადგილას
- [ ] head-ში
> წარწერა figure-ის ნაწილია.
