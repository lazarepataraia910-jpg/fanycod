## რას ისწავლი

- როგორ შექმნა ბმული, რომელიც წერილის დაწერას იწყებს
- როგორ შექმნა ბმული, რომელიც ტელეფონზე ნომერს კრეფს
- როგორ შეავსო წერილის სათაური და რა საფრთხე ახლავს მისამართის გამოქვეყნებას

## mailto: წერილის ბმული

ბმული ყოველთვის გვერდზე არ მიდის. თუ `href` იწყება `mailto:`-ით, დაჭერისას ბრაუზერი მომხმარებლის ფოსტის პროგრამას ხსნის და მიმღების ველში უკვე ჩაწერილია მისამართი:

```html
<a href="mailto:info@example.com">მოგვწერე: info@example.com</a>
```

`mailto:`-ს შემდეგ ინტერვალი არ იწერება. ბმულის ტექსტში კარგია, თვითონ მისამართიც ჩანდეს: ზოგ მომხმარებელს ფოსტის პროგრამა არ აქვს მომართული, და მაშინ მისამართის კოპირება მოუწევს.

## სათაური და ტექსტი წინასწარ

მისამართის შემდეგ, `?`-ის მერე, შეგიძლია წერილის სათაურიც (`subject`) და ტექსტიც (`body`) წინასწარ შეავსო. რამდენიმე პარამეტრს `&` აერთებს:

```html
<a href="mailto:olympiad@example.com?subject=რეგისტრაცია ოლიმპიადაზე">დარეგისტრირდი ფოსტით</a>
```

ეს ეხმარება მიმღებს: ყველა წერილს ერთნაირი სათაური ექნება და მათ დალაგება ადვილი იქნება. ერთი შენიშვნა: HTML-ში `&` ერთეულების დასაწყისია, ამიტომ ატრიბუტში მისი სწორი ჩანაწერია `&amp;`: `?subject=...&amp;body=...`. ბრაუზერები `&`-საც ხშირად იგებენ, მაგრამ `&amp;` ყველგან სწორია.

## tel: ტელეფონის ბმული

`tel:`-ით დაწყებული ბმული ტელეფონზე ზარის ფანჯარას ხსნის, უკვე აკრეფილი ნომრით. კომპიუტერზე ის შეიძლება ზარის პროგრამა გახსნას, ან არაფერი მოხდეს.

```html
<a href="tel:+995555123456">დაგვირეკე: 555 12 34 56</a>
```

ნომერი `href`-ში **საერთაშორისო ფორმატით** ჩაწერე: `+`, ქვეყნის კოდი (საქართველო 995) და ნომერი, ინტერვალების და ტირეების გარეშე. ასე ის ნებისმიერი ქვეყნიდან იმუშავებს. ბმულის ტექსტი კი შეგიძლია ისე დაწერო, როგორც ადამიანისთვის მოსახერხებელია: ინტერვალებით.

ზოგ ტელეფონში ასევე მუშაობს `sms:`, რომელიც შეტყობინების ფანჯარას ხსნის, მაგრამ მისი ქცევა სხვადასხვა მოწყობილობაზე განსხვავებულია.

## ელფოსტა და სპამი

ინტერნეტში არსებობს პროგრამები, რომლებიც მილიონობით გვერდს ათვალიერებს და მათში ელფოსტის მისამართებს აგროვებს, რომ მერე მათზე სპამი, უსარგებლო რეკლამა გააგზავნოს. გვერდზე ღიად დაწერილი მისამართი ადრე თუ გვიან სპამს მიიღებს. ამიტომ:

- **არასოდეს გამოაქვეყნო** შენი პირადი ელფოსტა ან ტელეფონი საჯარო გვერდზე. ეს განსაკუთრებით ეხება ბავშვებს: პირადი მონაცემები მხოლოდ მშობლის ნებართვით.
- საიტისთვის ცალკე მისამართი გამოიყენე, მაგალითად `info@...` ან `contact@...`.
- ბევრი საიტი ელფოსტის ნაცვლად საკონტაქტო ფორმას იყენებს: ფორმებს ამ კურსში მალე ისწავლი.

ამ თავის მაგალითებში ყველა მისამართი `example.com`-ზეა. ეს სპეციალურად მაგალითებისთვის დაცული დომენია და ის არავის ეკუთვნის.

## სცადე თავად

ეს რედაქტორი დაცულ ფანჯარაში მუშაობს, ამიტომ ფოსტის პროგრამა აქედან შეიძლება არ გაიხსნას. შეამოწმე კოდი შენს `.html` ფაილში, ტელეფონის ბმული კი ტელეფონზე.

```html run
<h2>კონტაქტი</h2>
<p>ფოსტა: <a href="mailto:info@example.com?subject=კითხვა საიტიდან">info@example.com</a></p>
<p>ტელეფონი: <a href="tel:+995555123456">555 12 34 56</a></p>
```

## ხშირი შეცდომები

- **`mailto`-ს შემდეგ ორწერტილის დავიწყება.** `href="mailtoinfo@example.com"` ფაილის სახელია. სწორია `mailto:info@example.com`.
- **ნომერი ინტერვალებით `href`-ში.** ზოგი ტელეფონი ინტერვალებს ვერ გაიგებს. `href`-ში `+995555123456`.
- **პირადი მისამართი საჯარო გვერდზე.** ის სპამის სიაში მოხვდება.

## შეჯამება

- `mailto:` ფოსტის პროგრამას ხსნის. `?subject=` სათაურს წინასწარ წერს.
- `tel:` ტელეფონზე ნომერს კრეფს. `href`-ში საერთაშორისო ფორმატი, ინტერვალების გარეშე.
- ბმულის ტექსტში მისამართი ან ნომერი ადამიანისთვის მოსახერხებლად დაწერე.
- პირადი კონტაქტები საჯარო გვერდზე არ გამოაქვეყნო.
