## რას ისწავლი

- როგორ გახსნა ბმული ახალ ჩანართში
- რისთვის გჭირდება `rel="noopener"`
- როდის არ ღირს ახალი ჩანართი და როგორ მუშაობს `download`

## target="_blank"

ნაგულისხმევად ბმული იმავე ჩანართში იხსნება: ძველი გვერდი ქრება, ახალი ჩნდება, ხოლო „უკან“ ღილაკი გაბრუნებს. თუ გინდა, რომ ბმული **ახალ ჩანართში** გაიხსნას, დაამატე `target` ატრიბუტი მნიშვნელობით `_blank`:

```html
<a href="https://developer.mozilla.org" target="_blank" rel="noopener">MDN (ახალ ჩანართში)</a>
```

ქვედა ტირე `_blank`-ის დასაწყისში მნიშვნელოვანია: ეს სპეციალური სახელია, რომელიც ნიშნავს „ახალი, ცარიელი ჩანართი“.

## rel="noopener"

`rel` ატრიბუტი ბმულსა და სამიზნე გვერდს შორის კავშირს აღწერს. `noopener` ნიშნავს: ახალმა ჩანართმა ძველზე „ხელი“ ვერ უნდა მიაწვდინოს. ძველ ბრაუზერებში ახალ ჩანართში გახსნილ გვერდს შეეძლო ის გვერდი, საიდანაც მოვიდა, სხვა მისამართზე, მაგალითად თაღლითურ საიტზე გადაემისამართებინა. თანამედროვე ბრაუზერები ამას ნაგულისხმევად კრძალავენ, მაგრამ `rel="noopener"` მაინც კარგი ჩვევაა: ის ძველ ბრაუზერებსაც იცავს და კოდის მკითხველს ნათლად ეუბნება, რა ხდება.

## როდის გახსნა ახალ ჩანართში

ახალი ჩანართი მომხმარებელს ხშირად აღიზიანებს: „უკან“ ღილაკი აღარ მუშაობს, ტელეფონზე კი ჩანართებს შორის გადართვა მოუხერხებელია. ამიტომ ბევრი გამოცდილი დეველოპერი ასე ფიქრობს: **ნაგულისხმევად ჩვეულებრივი ბმული, ახალი ჩანართი მხოლოდ საჭიროებისას.** კარგი მიზეზებია:

- ბმული ისეთ გვერდზე, სადაც მომხმარებელი რამეს ავსებს და მისი დატოვება შეუძლია ჩანაწერს დაკარგავს, მაგალითად ფორმაზე, ტესტზე ან თამაშზე;
- ფაილი, როგორიცაა PDF, რომელსაც გვერდიგვერდ ათვალიერებენ;
- დახმარების ან წესების გვერდი, რომელიც ძირითად საქმეს არ უნდა აწყვეტინებდეს.

თუ ბმული ახალ ჩანართში იხსნება, კარგია, ეს ტექსტშიც ეწეროს: „(ახალ ჩანართში)“ ან პატარა ხატულა ↗. მოულოდნელად გახსნილი ჩანართი ბევრს აბნევს, განსაკუთრებით ეკრანის წამკითხველის მომხმარებლებს.

## ჩამოტვირთვა: download

ზოგჯერ ბმულით ფაილის **ჩამოტვირთვა** გინდა და არა ბრაუზერში გახსნა. ამისთვის არსებობს `download` ატრიბუტი:

```html
<a href="files/schedule.pdf" download>ჩამოტვირთე განრიგი (PDF)</a>
<a href="files/schedule.pdf" download="ganrigi-2026.pdf">ჩამოტვირთე განრიგი</a>
```

პირველი ფაილს თავისი სახელით ჩამოტვირთავს, მეორე ახალი სახელით. `download` მხოლოდ შენი საიტის ფაილებზე მუშაობს: სხვა საიტის ფაილს ბრაუზერი უბრალოდ გახსნის.

## სცადე თავად

ეს რედაქტორი დაცულ ფანჯარაში მუშაობს და ახალ ჩანართებს არ ხსნის, ამიტომ აქ ბმულები შეიძლება არ გაიხსნას. ნახე, როგორ გამოიყურება კოდი, და შეამოწმე შენს `.html` ფაილში.

```html run
<p><a href="https://developer.mozilla.org" target="_blank" rel="noopener">MDN-ის დოკუმენტაცია (ახალ ჩანართში) ↗</a></p>
<p><a href="https://codequest.space/learn/">სკოლა (იმავე ჩანართში)</a></p>
<p><a href="/icons/icon-512.png" download="biti.png">ჩამოტვირთე ბიტის სურათი</a></p>
```

## ხშირი შეცდომები

- **`target="blank"` ქვედა ტირის გარეშე.** ეს სხვა რამეს ნიშნავს: ჩანართს სახელად blank. პირველ დაჭერაზე ახალი ჩანართი გაიხსნება, მეორეზე კი იგივე ხელახლა გამოიყენება.
- **ყველა ბმული ახალ ჩანართში.** მომხმარებელი ათობით ჩანართში იკარგება.
- **გაუფრთხილებლად ახალი ჩანართი.** დაწერე ტექსტში, რომ ბმული ახალ ჩანართში იხსნება.

## შეჯამება

- `target="_blank"` ბმულს ახალ ჩანართში ხსნის, `rel="noopener"` კი ძველ გვერდს იცავს.
- ახალი ჩანართი მხოლოდ საჭიროებისას, და მომხმარებელს გააფრთხილე.
- `download` ფაილს ჩამოტვირთავს. მნიშვნელობით ფაილს ახალ სახელს აძლევ.
- `_blank` ქვედა ტირით იწერება.
