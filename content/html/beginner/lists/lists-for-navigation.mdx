## რას ისწავლი

- რატომ იწერება საიტის მენიუ ბმულების სიად
- რას აკეთებს `<nav>` ელემენტი
- როგორ მონიშნო, რომელ გვერდზე იმყოფება მომხმარებელი

## მენიუ = ბმულების სია

ნებისმიერი საიტის თავში არის მენიუ: „მთავარი“, „ჩვენ შესახებ“, „კონტაქტი“. ეკრანზე ის ხშირად ჰორიზონტალურ ზოლად გამოიყურება, მარკერების გარეშე, და სულაც არ ჰგავს სიას. მაგრამ თავისი შინაარსით ის **ბმულების სიაა**. ამიტომ თითქმის ყველა საიტზე მენიუ ასე იწერება:

```html
<nav>
  <ul>
    <li><a href="index.html">მთავარი</a></li>
    <li><a href="about.html">ჩვენ შესახებ</a></li>
    <li><a href="gallery.html">გალერეა</a></li>
    <li><a href="contact.html">კონტაქტი</a></li>
  </ul>
</nav>
```

ჰორიზონტალური განლაგება, მარკერების მოშორება და ფერები მოგვიანებით CSS-ით გაკეთდება. HTML ამბობს მხოლოდ იმას, რაც მნიშვნელოვანია: ეს ოთხი ბმულის სიაა. ასე აგებული მენიუ ტელეფონზეც მარტივად გადაკეთდება: ვიწრო ეკრანზე CSS-ს შეუძლია იგივე სია ვერტიკალურად ან „ჰამბურგერ“ ღილაკის ქვეშ აჩვენოს, HTML-ის შეუცვლელად.

## nav ელემენტი

`<nav>` (navigation, ნავიგაცია) ამბობს: „აქ საიტის მთავარი ნავიგაციის ბმულებია“. ეკრანზე ის არაფრით გამოირჩევა, მაგრამ ეკრანის წამკითხველის მომხმარებლებს ძალიან ეხმარება: მათ შეუძლიათ ერთი ღილაკით პირდაპირ მენიუზე გადახტნენ, ან, პირიქით, გამოტოვონ ის და პირდაპირ შინაარსზე გადავიდნენ. წარმოიდგინე, რომ ყოველ გვერდზე იძულებული ხარ, ერთი და იგივე ათი ბმული მოისმინო, სანამ ტექსტამდე მიხვალ. `<nav>` ამ პრობლემას აგვარებს.

`<nav>` მხოლოდ მნიშვნელოვანი ნავიგაციისთვისაა: საიტის მთავარი მენიუ, სტატიის სარჩევი, „წინა / შემდეგი“ გვერდები. ძირში მიმოფანტული ცალკეული ბმულები, მაგალითად „კონფიდენციალურობის პოლიტიკა“, `<nav>`-ს არ საჭიროებს. გვერდის ნაწილებს, მათ შორის `<nav>`-ს, ამ კურსის ბოლოსწინა მოდულში დაწვრილებით გავარჩევთ.

## რომელ გვერდზე ვარ

კარგი მენიუ გიჩვენებს, სად ხარ ახლა: მიმდინარე გვერდის ბმული სხვანაირად გამოიყურება. ამის ჩასაწერად არსებობს ატრიბუტი `aria-current="page"`:

```html
<li><a href="about.html" aria-current="page">ჩვენ შესახებ</a></li>
```

ეკრანის წამკითხველი ასეთ ბმულს გამოაცხადებს როგორც „მიმდინარე გვერდი“, ხოლო CSS-ში შეგიძლია ის, მაგალითად, გაამუქო ან ხაზი გაუსვა. `aria-` ატრიბუტები სპეციალურად ხელმისაწვდომობისთვის შეიქმნა: ისინი დამხმარე ტექნოლოგიებს ისეთ ინფორმაციას აწვდის, რომელიც ჩვეულებრივ HTML ელემენტებში არ ჩანს.

## ქვემენიუ

თუ მენიუს პუნქტს ქვეპუნქტები აქვს, გამოიყენე წინა თავებში ნასწავლი ჩადგმული სია: შიდა `<ul>` მშობელი `<li>`-ის შიგნით.

## სცადე თავად

გაუშვი. ეს მენიუ ჯერ ჩვეულებრივ სიად გამოიყურება, CSS-ს ჯერ არ ვიყენებთ. ნახე, რომელ ბმულს აქვს `aria-current`, და გადაიტანე ის „გალერეაზე“.

```html run
<nav>
  <ul>
    <li><a href="#home">მთავარი</a></li>
    <li><a href="#about" aria-current="page">ჩვენ შესახებ</a></li>
    <li><a href="#gallery">გალერეა</a></li>
    <li><a href="#contact">კონტაქტი</a></li>
  </ul>
</nav>
<h1>ჩვენ შესახებ</h1>
<p>ჩვენ ბიტის გუნდი ვართ და პროგრამირება გვიყვარს.</p>
```

## ხშირი შეცდომები

- **მენიუ ბმულებით, მაგრამ სიის გარეშე.** ოთხი ბმული ზედიზედ ეკრანზე იგივეა, მაგრამ წამკითხველისთვის სია უფრო ინფორმაციულია: „სია, ოთხი პუნქტი“.
- **ყველა ბმული `<nav>`-ში.** მხოლოდ მთავარი ნავიგაცია.
- **`aria-current` ყველა ბმულზე.** ის მხოლოდ ერთ, მიმდინარე გვერდის ბმულს უნდა ჰქონდეს.

## შეჯამება

- საიტის მენიუ ბმულების სიაა: `<nav><ul><li><a>`.
- `<nav>` მთავარ ნავიგაციას აღნიშნავს და ეკრანის წამკითხველს ეხმარება.
- მიმდინარე გვერდის ბმულს `aria-current="page"` მიეცი.
- ჰორიზონტალური მენიუ და მარკერების მოშორება CSS-ის საქმეა.
