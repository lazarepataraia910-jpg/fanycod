## რას ისწავლი

- როგორ შექმნა დანომრილი სია `<ol>`-ით
- როგორ დაიწყო ნუმერაცია სხვა რიცხვიდან და როგორ ითვალო უკან
- როგორ გამოიყენო ასოები ან რომაული რიცხვები

## როცა რიგს მნიშვნელობა აქვს

რეცეპტში ჯერ კვერცხს ამტვრევ და მერე წვავ, და არა პირიქით. ინსტრუქციაში ჯერ ფაილს ინახავ და მერე ხურავ. რეიტინგში პირველი ადგილი პირველია. ასეთი სიისთვის HTML-ს **დანომრილი სია (ordered list)** აქვს:

```html
<h2>როგორ მოვამზადოთ ერბოკვერცხი</h2>
<ol>
  <li>გააცხელე ტაფა და დაადე კარაქი.</li>
  <li>ჩატეხე ორი კვერცხი.</li>
  <li>მოაყარე მარილი.</li>
  <li>შეწვი სამი წუთი.</li>
</ol>
```

`<ol>` (ordered list) დაუნომრავი სიის მსგავსად მუშაობს, მხოლოდ ბრაუზერი წერტილების ნაცვლად ნომრებს წერს: 1, 2, 3, 4. პუნქტები ისევ `<li>` ელემენტებია: სიის ტიპს მხოლოდ გარე ელემენტი, `<ul>` თუ `<ol>`, განსაზღვრავს.

## ნომრები ავტომატურად

მთავარი უპირატესობა: ნომრებს ბრაუზერი თვითონ ითვლის. თუ შუაში ახალ ნაბიჯს ჩასვამ, ყველა შემდეგი ნომერი თავისით განახლდება. ხელით დაწერილი „1. … 2. … 3. …“ ყოველი ცვლილებისას ხელით გადასანომრი იქნებოდა, ამასთან ეკრანის წამკითხველი ვერ გაიგებდა, რომ ეს თანმიმდევრული ნაბიჯებია.

## start: სხვა რიცხვიდან

თუ სია წინა სიის გაგრძელებაა, მაგალითად ინსტრუქციის ნაწილებს შორის სურათია, ნუმერაცია სხვა რიცხვიდან შეიძლება დაიწყო:

```html
<ol start="5">
  <li>შეინახე ფაილი.</li>
  <li>გახსენი ბრაუზერში.</li>
</ol>
```

ეს სია 5-ით და 6-ით დაინომრება.

## reversed: უკუთვლა

`reversed` ატრიბუტი ნუმერაციას აბრუნებს: ბოლო პუნქტი იქნება 1. იდეალურია რეიტინგებისთვის, სადაც „ხუთეულს“ ბოლოდან ითვლიან:

```html
<h2>ჩემი ტოპ-3 ფილმი</h2>
<ol reversed>
  <li>ტოი სტორი</li>
  <li>ვოლ-ი</li>
  <li>ზღარბი სონიკი</li>
</ol>
```

ნომრები იქნება 3, 2, 1. ყურადღება მიაქციე: `reversed`-ს მნიშვნელობა არ სჭირდება. ასეთ ატრიბუტს **ლოგიკური ატრიბუტი (boolean attribute)** ჰქვია: მისი არსებობა ნიშნავს „კი“, არარსებობა „არა“.

## type: ასოები და რომაული რიცხვები

`type` ატრიბუტი ნუმერაციის სახეს ცვლის:

- `type="1"` — 1, 2, 3 (ნაგულისხმევი);
- `type="a"` — a, b, c;
- `type="A"` — A, B, C;
- `type="i"` — i, ii, iii;
- `type="I"` — I, II, III.

ეს გამოგადგება, მაგალითად, ტესტის პასუხის ვარიანტებისთვის (a, b, c) ან წიგნის თავებისთვის (I, II, III). თუ სახე მხოლოდ გარეგნობაა და აზრს არ ცვლის, ჯობს CSS-ით შეცვალო.

## სცადე თავად

გაუშვი. მერე რეცეპტს შუაში დაამატე ნაბიჯი და ნახე, როგორ გადაინომრა დანარჩენი. ბოლო სიას `reversed` წაუშალე.

```html run
<h2>ერბოკვერცხი</h2>
<ol>
  <li>გააცხელე ტაფა.</li>
  <li>ჩატეხე კვერცხი.</li>
  <li>შეწვი სამი წუთი.</li>
</ol>

<h2>ტოპ-3 ხილი</h2>
<ol reversed>
  <li>ატამი</li>
  <li>ყურძენი</li>
  <li>ლეღვი</li>
</ol>

<h2>ტესტი</h2>
<ol type="a">
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ol>
```

## ხშირი შეცდომები

- **ნომრები ხელით.** `<li>1. გააცხელე ტაფა</li>` ორმაგ ნომერს მისცემს: „1. 1. გააცხელე“. ნომრებს ბრაუზერი წერს.
- **`<ol>` იქ, სადაც რიგი არ არის.** საყიდლების სიას ნომრები არ სჭირდება.
- **`reversed="true"`.** ლოგიკურ ატრიბუტს მნიშვნელობა არ სჭირდება, საკმარისია `reversed`.

## შეჯამება

- დანომრილი სია: `<ol>` და მასში `<li>`. ნომრებს ბრაუზერი თვითონ ითვლის.
- გამოიყენე, როცა რიგი მნიშვნელოვანია: ნაბიჯები, რეიტინგი, ინსტრუქცია.
- `start` სხვა რიცხვიდან იწყებს, `reversed` უკან ითვლის, `type` ასოებს ან რომაულ რიცხვებს რთავს.
- ნომრებს ხელით არ წერ: ცვლილებისას ისინი თვითონ გადაინომრება.
