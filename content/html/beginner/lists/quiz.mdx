შეამოწმე, რა დაგამახსოვრდა სიებზე. თითო კითხვას ერთი სწორი პასუხი აქვს. გასავლელად საჭიროა 70%.

<Quiz>
### რომელი სია გამოიყენო საყიდლების ჩამონათვალისთვის?
- [x] ul
- [ ] ol
- [ ] dl
> საყიდლების რიგს მნიშვნელობა არ აქვს.

### რომელი სია გამოიყენო რეცეპტის ნაბიჯებისთვის?
- [ ] ul
- [x] ol
- [ ] dl
> ნაბიჯების რიგი მნიშვნელოვანია.

### რა შეიძლება იყოს `<ul>`-ის პირდაპირი შვილი?
- [ ] p
- [x] li
- [ ] ნებისმიერი ელემენტი
> ul-სა და ol-ში პირდაპირ მხოლოდ li.

### რატომ არ წერენ ნომრებს `<ol>`-ის პუნქტებში ხელით?
- [x] ბრაუზერი ნომრებს თვითონ ითვლის და ცვლილებისას გადანომრავს
- [ ] ნომრები HTML-ში აკრძალულია
- [ ] ხელით ნომრები ეკრანზე არ ჩანს
> ხელით დაწერილი ნომერი გაორმაგდება.

### რომელი ატრიბუტი ითვლის უკან, 3, 2, 1?
- [x] reversed
- [ ] start
- [ ] type
> reversed ლოგიკური ატრიბუტია და მნიშვნელობა არ სჭირდება.

### რომელი ატრიბუტი ცვლის ნუმერაციას ასოებად: a, b, c?
- [ ] start="a"
- [x] type="a"
- [ ] reversed="a"
> type ნუმერაციის სახეს ცვლის.

### სად უნდა იყოს ჩადგმული სია?
- [x] მშობელი li-ის შიგნით
- [ ] პირდაპირ გარე ul-ში
- [ ] სიის გარეთ
> ქვეპუნქტები მშობელ პუნქტს ეკუთვნის.

### განმარტებების სიაში რომელი ელემენტია განმარტება?
- [ ] dt
- [x] dd
- [ ] dl
> dl სია, dt ტერმინი, dd განმარტება.

### რომელი ელემენტი აღნიშნავს საიტის მთავარ მენიუს?
- [ ] menu
- [x] nav
- [ ] header
> nav = navigation.

### რას აკეთებს `aria-current="page"`?
- [x] მონიშნავს მიმდინარე გვერდის ბმულს
- [ ] ბმულს ახალ ჩანართში ხსნის
- [ ] ბმულს მალავს
> წამკითხველი მას „მიმდინარე გვერდად“ აცხადებს.
