შეამოწმე, რა დაგამახსოვრდა გვერდის ნაწილებზე. თითო კითხვას ერთი სწორი პასუხი აქვს. გასავლელად საჭიროა 70%.

<Quiz>
### რომელი ელემენტია სტრიქონული ყუთი მნიშვნელობის გარეშე?
- [ ] div
- [x] span
- [ ] section
> div ბლოკურია, span სტრიქონული.

### რომელი კლასის სახელია უკეთესი გაფრთხილებისთვის?
- [x] warning
- [ ] red-bold
- [ ] text1
> სახელი შინაარსს აღწერს, არა გარეგნობას.

### სად წერია საიტის ლოგო და მენიუ?
- [x] header-ში
- [ ] head-ში
- [ ] footer-ში
> head უხილავია, header ხილული თავი.

### რა იწერება `<footer>`-ში?
- [ ] მთავარი სტატია
- [x] საავტორო უფლებები და კონტაქტი
- [ ] title
> footer გვერდის ან ნაწილის ძირია.

### როგორ განასხვავო ერთ გვერდზე ორი `<nav>`?
- [x] aria-label-ით
- [ ] id-ით
- [ ] ფერით
> aria-label ეკრანის წამკითხველისთვისაა.

### რამდენი ხილული `<main>` შეიძლება იყოს გვერდზე?
- [x] ერთი
- [ ] ორი
- [ ] შეუზღუდავი
> მთავარი შინაარსი ერთია.

### რა სჭირდება `<section>`-ს?
- [x] სათაური
- [ ] სურათი
- [ ] aria-label
> სათაურის გარეშე div ჯობს.

### რომელი ელემენტი შეეფერება კომენტარს სტატიის ქვეშ?
- [x] article
- [ ] aside
- [ ] nav
> კომენტარი დამოუკიდებელი შინაარსია.

### რომელი ელემენტი შეეფერება „იცოდით?“ ჩანართს სტატიის გვერდით?
- [ ] main
- [x] aside
- [ ] footer
> aside დამატებითი, გვერდითი შინაარსია.

### რა არის მთავარი წესი გვერდის ნაწილების არჩევისას?
- [ ] ყველგან div
- [x] ყოველ ნაწილს მიეცი ელემენტი, რომელიც მას ზუსტად აღწერს; თუ არცერთი, div
- [ ] ელემენტი აირჩიე იმის მიხედვით, როგორ გამოიყურება
> ეს სემანტიკური HTML-ის არსია.
