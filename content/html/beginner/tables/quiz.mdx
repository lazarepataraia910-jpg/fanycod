შეამოწმე, რა დაგამახსოვრდა ცხრილებზე. თითო კითხვას ერთი სწორი პასუხი აქვს. გასავლელად საჭიროა 70%.

<Quiz>
### რომელი ელემენტია ჩვეულებრივი უჯრა მონაცემით?
- [x] td
- [ ] tr
- [ ] th
> td = table data.

### რა არის სწორი ჩადგმა?
- [x] table > tr > td
- [ ] table > td > tr
- [ ] tr > table > td
> ცხრილში სტრიქონები, სტრიქონებში უჯრები.

### რა უნდა იყოს ყველა სტრიქონში ერთნაირი?
- [ ] ტექსტის სიგრძე
- [x] უჯრების (სვეტების) რაოდენობა, გაერთიანებების გათვალისწინებით
- [ ] ფერი
> სხვადასხვა რაოდენობა ცხრილს „დაკბიჩავს“.

### რომელ ნაწილში იწერება „სულ“-ის სტრიქონი?
- [ ] thead
- [ ] tbody
- [x] tfoot
> tfoot შეჯამებისთვისაა.

### რას აკეთებს `scope="col"`?
- [x] ამბობს, რომ სათაურის უჯრა თავის სვეტს ასათაურებს
- [ ] სვეტს აფართოებს
- [ ] სვეტს მალავს
> col = სვეტი, row = სტრიქონი.

### ცხრილს 3 სვეტი აქვს. რამდენი `<td>` იქნება სტრიქონში, რომლის ერთ უჯრას `colspan="3"` აქვს?
- [x] 1
- [ ] 3
- [ ] 2
> ერთი უჯრა სამივე სვეტს იკავებს.

### ზედა უჯრას `rowspan="2"` აქვს. რა იწერება ქვედა სტრიქონში მის ადგილას?
- [ ] ცარიელი td
- [x] არაფერი
- [ ] იგივე ტექსტი
> ადგილი ზემოდან ჩამოსული უჯრით არის დაკავებული.

### სად იწერება `<caption>`?
- [x] table-ის პირველ შვილად
- [ ] thead-ის შიგნით
- [ ] table-ის გარეთ
> caption ყველა სტრიქონის წინ მოდის.

### რომელი მონაცემი არ სჭირდება ცხრილს?
- [ ] კვირის ამინდი დღეების მიხედვით
- [ ] ტურნირის ცხრილი
- [x] ჩემი სამი საყვარელი ფილმი
> ერთგანზომილებიანი ჩამონათვალი სიაა.

### რით ეწყობა დღეს გვერდის განლაგება, მაგალითად სვეტები?
- [ ] ცხრილით
- [x] CSS-ით
- [ ] ბევრი br-ით
> ცხრილი მხოლოდ მონაცემებისთვის.
