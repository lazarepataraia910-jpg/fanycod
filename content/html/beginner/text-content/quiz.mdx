შეამოწმე, რა დაგამახსოვრდა ტექსტის ელემენტებზე. თითო კითხვას ერთი სწორი პასუხი აქვს. გასავლელად საჭიროა 70%.

<Quiz>
### რომელია ყველაზე მნიშვნელოვანი სათაური?
- [x] h1
- [ ] h6
- [ ] header
> რიცხვი დონეა: 1 ყველაზე მაღალი.

### `<h2>`-ის შემდეგ შენ `<h4>` დაწერე, რადგან პატარა შრიფტი გინდოდა. რა არის პრობლემა?
- [ ] არაფერი
- [x] დონე გამოტოვებულია და გეგმა ირღვევა. ზომა CSS-ით იცვლება
- [ ] h4 არ არსებობს
> სათაური მნიშვნელობით ირჩევა.

### კოდში ტექსტი სამ ხაზზე წერია `<p>`-ის შიგნით. როგორ გამოჩნდება?
- [ ] სამ ხაზზე
- [x] ერთ ხაზზე, ინტერვალებით
- [ ] საერთოდ არ გამოჩნდება
> ახალი ხაზები ინტერვალებად იკუმშება.

### რომელი ელემენტი წყვეტს ხაზს აბზაცის შიგნით?
- [x] br
- [ ] hr
- [ ] pre
> hr თემის ცვლილებაა, pre ინტერვალებს ინარჩუნებს.

### რომელი ელემენტი ნიშნავს მნიშვნელოვან, სერიოზულ ტექსტს?
- [ ] b
- [x] strong
- [ ] mark
> b მხოლოდ მუქია.

### როგორ დაწერო წყლის ფორმულა H₂O?
- [x] H<sub>2</sub>O
- [ ] H<sup>2</sup>O
- [ ] H<small>2</small>O
> sub ქვემოთ წერს.

### რომელი ელემენტი გამოიყენო ფილმის სახელისთვის?
- [ ] q
- [x] cite
- [ ] blockquote
> cite ნაწარმოების სახელია.

### რატომ არ წერ ბრჭყალებს `<q>` ელემენტში?
- [x] ბრაუზერი მათ თვითონ ამატებს
- [ ] q-ში ბრჭყალები აკრძალულია
- [ ] ბრჭყალები ტექსტს მალავს
> ხელით დაწერილი ბრჭყალები გაორმაგდება.

### რომელი ელემენტია კლავიატურის ღილაკისთვის?
- [ ] code
- [x] kbd
- [ ] key
> kbd = keyboard.

### როგორ აჩვენო გვერდზე ტექსტი `A & B`?
- [ ] A && B
- [x] A &amp; B
- [ ] A &and; B
> ამპერსანდი ერთეულებს იწყებს, ამიტომ მისი ერთეულია `&amp;`.
