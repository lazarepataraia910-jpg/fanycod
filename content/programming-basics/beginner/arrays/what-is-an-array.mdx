## რას ისწავლი

- რა არის მასივი (array) და რა პრობლემას წყვეტს
- როგორ შექმნა მასივი და დაბეჭდო ის
- როგორ გაიგო, რამდენი ელემენტია მასივში

## ოცდაათი ცვლადი თუ ერთი სია

კლასში 30 მოსწავლეა და ყველას ქულა უნდა შეინახო. ცვლადებით ასე გამოვიდოდა: `score1`, `score2`, `score3` და ასე ოცდაათამდე. მერე საშუალოს დასათვლელად ყველა ცვლადი ხელით უნდა ჩამოწერო. და თუ ახალი მოსწავლე მოვიდა? ახალი ცვლადი და კოდის ცვლილება ყველგან.

ასეთი რამისთვის არსებობს **მასივი (array)**: ერთი ცვლადი, რომელიც ბევრ მნიშვნელობას ინახავს, რიგით, ერთმანეთის მიყოლებით. როგორც საყიდლების სია ქაღალდზე: ერთი ფურცელი, ბევრი ჩანაწერი.

```js
let fruits = ["ვაშლი", "მსხალი", "ატამი"];
let scores = [90, 75, 100, 64];
let empty = [];

console.log(fruits);   // ["ვაშლი","მსხალი","ატამი"]
console.log(scores);   // [90,75,100,64]
```

1. მასივი კვადრატულ ფრჩხილებში `[ ]` იწერება.
2. მნიშვნელობები მძიმით გამოიყოფა. თითოეულ მათგანს **ელემენტი (element)** ჰქვია.
3. მასივი ცარიელიც შეიძლება იყოს: `[]`. ასეთ სიას მერე შეავსებ.

ცვლადს, რომელშიც მასივი ინახება, ჩვეულებრივ მრავლობითი რიცხვის სახელს ვარქმევთ: `fruits`, `scores`, `players`. ასე კოდის კითხვისას მაშინვე ჩანს, რომ შიგნით ერთი კი არა, ბევრი რამეა.

## რიგი მნიშვნელოვანია

მასივში ელემენტებს თავისი ადგილი აქვს: პირველი, მეორე, მესამე. რიგი არ იცვლება, თუ თვითონ არ შეცვალე. ამიტომ მასივი კარგია ყველაფრისთვის, სადაც თანმიმდევრობა მნიშვნელოვანია: რიგი მაღაზიაში, თამაშის დონეები, ჩატის შეტყობინებები, საუკეთესო შედეგების ცხრილი.

შემდეგ თავში ისწავლი, როგორ წაიკითხო ელემენტი მისი ადგილის მიხედვით. ერთი და იგივე მნიშვნელობა მასივში რამდენჯერმე შეიძლება შეგხვდეს: `[95, 80, 95]` სავსებით სწორი მასივია, რადგან ორმა მოსწავლემ შეიძლება ერთნაირი ქულა მიიღოს.

## რამდენი ელემენტია

სტრიქონის მსგავსად, მასივსაც აქვს `.length`, რომელიც ელემენტების რაოდენობას გეუბნება:

```js
let fruits = ["ვაშლი", "მსხალი", "ატამი"];
console.log(fruits.length);   // 3
console.log([].length);       // 0
```

## რა შეიძლება ჩაიწეროს მასივში

მასივში ნებისმიერი მნიშვნელობა შეიძლება ჩაიდოს: რიცხვები, სტრიქონები, ლოგიკური მნიშვნელობები, სხვა მასივებიც კი. JavaScript ერთ მასივში სხვადასხვა ტიპის შერევასაც უშვებს: `[12, "ანა", true]`. მაგრამ ჩვეულებრივ მასივში ერთი სახის მონაცემებს ვინახავთ: მხოლოდ ქულებს, მხოლოდ სახელებს. ასე მასთან მუშაობა ბევრად ადვილია.

## სცადე თავად

გაუშვი, მერე დაამატე მასივში კიდევ ორი ხილი და ნახე, როგორ შეიცვლება სიგრძე.

```js run
let fruits = ["ვაშლი", "მსხალი", "ატამი"];

console.log(fruits);
console.log("ხილის რაოდენობა:", fruits.length);
```

## ხშირი შეცდომები

- **მრგვალი ან ფიგურული ფრჩხილები.** `("ვაშლი", "მსხალი")` მასივი არ არის. მასივი მხოლოდ კვადრატულ ფრჩხილებში იწერება.
- **დავიწყებული მძიმე.** `["ვაშლი" "მსხალი"]` შეცდომაა. ელემენტებს შორის მძიმე სავალდებულოა.
- **ბრჭყალების გარეშე ტექსტი.** `[ვაშლი, მსხალი]`-ში კომპიუტერი ცვლადებს ეძებს, სახელად ვაშლი და მსხალი. ტექსტური ელემენტები ბრჭყალებში ჩაწერე.

## შეჯამება

- მასივი ბევრ მნიშვნელობას ერთ ცვლადში, რიგით ინახავს: `[1, 2, 3]`.
- თითოეულ მნიშვნელობას ელემენტი ჰქვია. ელემენტები მძიმით გამოიყოფა.
- `.length` ელემენტების რაოდენობას გეუბნება.
- მასივს მრავლობითი სახელი დაარქვი და მასში ერთი სახის მონაცემები შეინახე.
