## რას ისწავლი

- როგორ შეასრულო კოდი მხოლოდ მაშინ, როცა პირობა `true`-ა
- რა არის კოდის ბლოკი და რატომ ვწერთ შეწეულად
- რომელი პატარა შეცდომები აფუჭებს `if`-ს

## პროგრამა, რომელიც ირჩევს

აქამდე შენი პროგრამები ყოველთვის ერთსა და იმავეს აკეთებდა: ზემოდან ქვემოთ, ყველა ხაზს რიგრიგობით. ნამდვილი პროგრამები კი სიტუაციას ერგება. თამაში „თამაში დასრულდა“-ს მხოლოდ მაშინ წერს, როცა სიცოცხლე დაგიმთავრდა. ამინდის აპლიკაცია ქოლგას მხოლოდ მაშინ გირჩევს, როცა წვიმს.

ასეთ არჩევანს **პირობითი ინსტრუქცია (conditional statement)** აკეთებს. ყველაზე მარტივი მათგანია `if`, ინგლისურად „თუ“:

```js
let temperature = 32;

if (temperature > 30) {
  console.log("ცხელა! წყალი დალიე.");
}

console.log("ამინდის შემოწმება დასრულდა.");
```

1. `if`-ის შემდეგ მრგვალ ფრჩხილებში **პირობა** წერია. ეს არის გამოსახულება, რომელიც `true`-ს ან `false`-ს იძლევა.
2. ფიგურულ ფრჩხილებში `{ }` წერია კოდი, რომელიც მხოლოდ მაშინ შესრულდება, როცა პირობა `true`-ა.
3. ბოლო ხაზი `if`-ის გარეთაა, ამიტომ ყოველთვის სრულდება.

ახლა ორივე ხაზი დაიბეჭდება. თუ `temperature`-ში 20-ს ჩაწერ, პირველი შეტყობინება გაქრება, მეორე კი დარჩება.

## კოდის ბლოკი

ფიგურულ ფრჩხილებს შორის მოქცეულ კოდს **ბლოკი (block)** ჰქვია. ბლოკში რამდენიც გინდა, იმდენი ხაზი შეიძლება იყოს, და ყველა ერთად შესრულდება ან ერთად გამოტოვდება.

ბლოკის შიგნით ხაზებს ორი ინტერვალით შეწეულად ვწერთ. კომპიუტერს შეწევა არ სჭირდება, ადამიანს კი ძალიან: ერთი შეხედვით ჩანს, რომელი ხაზი ეკუთვნის `if`-ს. სხვისი კოდის კითხვისას შეწევა რუკასავითაა.

## რა შეიძლება იყოს პირობა

პირობაში ნებისმიერი გამოსახულება შეიძლება ჩაწერო, რომელიც `true`-ს ან `false`-ს იძლევა: შედარება, ლოგიკური ცვლადი, `&&`-ით და `||`-ით შეერთებული რამდენიმე პირობა.

```js
let isRaining = true;
let hasUmbrella = false;

if (isRaining && !hasUmbrella) {
  console.log("ქოლგა არ დაგავიწყდეს!");
}
```

ლოგიკურ ცვლადს `=== true` არ სჭირდება: `if (isRaining)` იგივეა, რაც `if (isRaining === true)`, მაგრამ უფრო მოკლე და ბუნებრივია.

## სცადე თავად

გაუშვი, მერე შეცვალე `coins` ისე, რომ შეტყობინება გაქრეს. რა არის ყველაზე პატარა რიცხვი, რომლითაც ჯერ კიდევ იბეჭდება?

```js run
let coins = 120;
let price = 100;

if (coins >= price) {
  console.log("ნივთი იყიდე!");
  coins -= price;
}

console.log("დარჩა მონეტა:", coins);
```

## ხშირი შეცდომები

- **`=` პირობაში.** `if (score = 100)` არ ადარებს, არამედ ცვლადს 100-ს ანიჭებს, და პირობა ყოველთვის სრულდება. შედარებისთვის `===` დაწერე.
- **წერტილ-მძიმე `if`-ის შემდეგ.** `if (x > 5); { ... }`-ში წერტილ-მძიმე `if`-ს ასრულებს და ბლოკი ყოველთვის სრულდება. `if (...)`-ის შემდეგ პირდაპირ `{` უნდა მოდიოდეს.
- **ფრჩხილების გამოტოვება.** ფიგურული ფრჩხილების გარეშე `if`-ს მხოლოდ მომდევნო ერთი ხაზი ეკუთვნის. ფრჩხილები ყოველთვის დაწერე, ერთი ხაზისთვისაც.

<Exercise>
ცვლადში `password` ინახება `"abc123"`. თუ პაროლი 8 სიმბოლოზე მოკლეა, დაბეჭდე `პაროლი მოკლეა: საჭიროა სულ მცირე 8 სიმბოლო`. მერე პაროლი შეცვალე უფრო გრძლით და შეამოწმე, რომ შეტყობინება ქრება.

```js run
let password = "abc123";
// შეამოწმე სიგრძე
```

<Hint>სტრიქონის სიგრძე `password.length`-ია. პირობაა `password.length < 8`.</Hint>

<Solution>
```js
let password = "abc123";

if (password.length < 8) {
  console.log("პაროლი მოკლეა: საჭიროა სულ მცირე 8 სიმბოლო");
}
```
</Solution>
</Exercise>

## შეჯამება

- `if (პირობა) { ... }` ბლოკს მხოლოდ მაშინ ასრულებს, როცა პირობა `true`-ა.
- ბლოკი ფიგურულ ფრჩხილებშია და შეწეულად იწერება.
- პირობა შეიძლება იყოს შედარება, ლოგიკური ცვლადი ან `&&`/`||`-ით შეერთებული პირობები.
- პირობაში `===`, არა `=`. `if (...)`-ის შემდეგ წერტილ-მძიმე არ იწერება.
