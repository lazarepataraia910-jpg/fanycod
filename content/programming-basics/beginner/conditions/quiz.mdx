შეამოწმე, რა დაგამახსოვრდა პირობებზე. თითო კითხვას ერთი სწორი პასუხი აქვს. გასავლელად საჭიროა 70%.

### როდის შესრულდება `if`-ის ბლოკი?
- [x] როცა პირობა true-ა
- [ ] როცა პირობა false-ა
- [ ] ყოველთვის, ერთხელ
> `if` ბლოკს მხოლოდ ჭეშმარიტი პირობისას ასრულებს.

### რას დაბეჭდავს? `let t = 18; if (t > 25) { console.log("ცხელა"); } else { console.log("გრილა"); }`
- [ ] ცხელა
- [x] გრილა
- [ ] ცხელა და გრილა
> 18 არ არის 25-ზე მეტი, ამიტომ სრულდება `else`.

### რას დაბეჭდავს ეს ჯაჭვი, თუ `n = 0`? `if (n > 0) {…"დადებითი"} else if (n < 0) {…"უარყოფითი"} else {…"ნული"}`
- [ ] დადებითი
- [ ] უარყოფითი
- [x] ნული
> არცერთი პირობა არ გამართლდა, ამიტომ სრულდება ბოლო `else`.

### რატომ უნდა დაიწყოს ქულების შემოწმება `score >= 90`-ით და არა `score >= 50`-ით?
- [x] რადგან ჯაჭვში პირველი true პირობა იმარჯვებს
- [ ] რადგან დიდი რიცხვები ყოველთვის ჯერ მოწმდება
- [ ] რიგს მნიშვნელობა არ აქვს
> თუ ჯერ `>= 50` მოწმდება, 95-იც „დამაკმაყოფილებელი“ გამოვა.

### რა არის შეცდომა ამ კოდში? `if (x > 5); { console.log("დიდია"); }`
- [ ] ფრჩხილები ზედმეტია
- [x] წერტილ-მძიმე if-ის შემდეგ, ამიტომ ბლოკი ყოველთვის სრულდება
- [ ] შეცდომა არ არის
> წერტილ-მძიმე if-ს ასრულებს. ბლოკი მის შემდეგ უბრალოდ ცალკე კოდია.

### რომელი ჩანაწერია ორი ჩადგმული `if`-ის (else-ების გარეშე) ტოლფასი?
- [ ] if (a || b)
- [x] if (a && b)
- [ ] if (!a)
> შიდა ბლოკი სრულდება, როცა ორივე პირობა true-ა.

### რას აკეთებს `break` switch-ში?
- [x] switch-იდან გამოდის
- [ ] პროგრამას აჩერებს
- [ ] შემდეგ case-ზე გადადის
> `break`-ის გარეშე კოდი შემდეგ case-ში „ჩავარდება“.

### `switch (color)`-ში არცერთი case არ დაემთხვა. რა შესრულდება?
- [ ] პირველი case
- [x] default
- [ ] არაფერი და შეცდომა
> `default` იმ შემთხვევისთვისაა, როცა არცერთი ვარიანტი არ დაემთხვა. თუ default არ არის, უბრალოდ არაფერი სრულდება.

### რა ინახება `r`-ში? `let r = 10 % 2 === 0 ? "ლუწი" : "კენტი";`
- [x] ლუწი
- [ ] კენტი
- [ ] 0
> 10-ის ორზე გაყოფის ნაშთი 0-ია, ამიტომ პირობა true-ა.

### როდის ჯობს `if / else` მოკლე პირობას?
- [ ] არასოდეს
- [x] როცა ორივე შემთხვევაში რამდენიმე მოქმედება სრულდება
- [ ] როცა ორი მოკლე მნიშვნელობიდან ერთი უნდა აირჩიო
> მოკლე პირობა მნიშვნელობის ასარჩევადაა. მოქმედებებისთვის `if` უფრო გასაგებია.
