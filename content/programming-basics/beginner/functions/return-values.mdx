## რას ისწავლი

- როგორ დააბრუნოს ფუნქციამ შედეგი `return`-ით
- რატომ არ არის `console.log` და `return` ერთი და იგივე
- რას აბრუნებს ფუნქცია `return`-ის გარეშე

## ფუნქცია, რომელიც პასუხს გაძლევს

აქამდე ჩვენი ფუნქციები ბეჭდავდა. ხშირად კი ფუნქციისგან პასუხი გვჭირდება, რომ მერე გამოვიყენოთ: შევინახოთ, შევადაროთ, სხვა გამოთვლაში ჩავსვათ. ამისთვის არსებობს `return`, „დააბრუნე“:

```js
function square(n) {
  return n * n;
}

let a = square(4);
console.log(a);              // 16
console.log(square(3) + 1);  // 10
```

`return n * n;` ამბობს: „გამოთვალე `n * n` და ეს მნიშვნელობა დაუბრუნე იმას, ვინც გამომიძახა“. ამიტომ გამოძახება `square(4)` თვითონ ხდება მნიშვნელობა, 16. ფუნქციის გამოძახება, რომელიც რამეს აბრუნებს, გამოსახულებაა: შეგიძლია ცვლადში შეინახო, მასზე მიუმატო, სხვა ფუნქციას გადასცე.

## დაბეჭდვა თუ დაბრუნება

ეს ორი სიტყვა ერთნაირად გამოიყურება, მაგრამ სულ სხვადასხვაა:

```js
function squarePrint(n) {
  console.log(n * n);
}

function squareReturn(n) {
  return n * n;
}

let x = squarePrint(5);    // ეკრანზე იბეჭდება 25
let y = squareReturn(5);   // ეკრანზე არაფერი, y-ში 25

console.log(x);   // undefined
console.log(y);   // 25
```

`console.log` შედეგს **ადამიანს** აჩვენებს ეკრანზე, მაგრამ პროგრამას არაფერს აძლევს. `return` შედეგს **პროგრამას** აძლევს, მაგრამ ეკრანზე არაფერს წერს. თუ შედეგის შემდგომ გამოყენებას აპირებ, `return` გჭირდება.

წესი, რომელსაც პროფესიონალებიც მიჰყვებიან: ფუნქციამ, რომელიც რამეს ითვლის, შედეგი დააბრუნოს. დაბეჭდოს იმ კოდმა, რომელმაც ის გამოიძახა.

რატომ? წარმოიდგინე კალკულატორი, რომელიც პასუხს მხოლოდ ხმამაღლა ამბობს, ეკრანზე კი არაფერს აჩვენებს. შემდეგ მოქმედებაში ამ პასუხს ვეღარ გამოიყენებ, ხელახლა უნდა აკრიფო. დაბრუნებული მნიშვნელობა კი ეკრანზე დარჩენილ რიცხვს ჰგავს: შეგიძლია მასზე მიუმატო, გაამრავლო ან სხვა ფუნქციას გადასცე. ასე პატარა ფუნქციები ერთმანეთს ეხმარება.

## return ასრულებს ფუნქციას

`return`-ზე ფუნქცია მაშინვე მთავრდება. მის შემდეგ დაწერილი კოდი აღარ სრულდება. ეს მოსახერხებელია, როცა პასუხი ადრე იცი:

```js
function isEven(n) {
  return n % 2 === 0;
}

function sign(n) {
  if (n > 0) {
    return "დადებითი";
  }
  if (n < 0) {
    return "უარყოფითი";
  }
  return "ნული";
}

console.log(isEven(10));   // true
console.log(sign(-4));     // უარყოფითი
```

`sign`-ში `else` არ გვჭირდება: თუ პირველი პირობა გამართლდა, `return` ფუნქციას ასრულებს და დანარჩენი ხაზები აღარ მოწმდება.

## ფუნქცია return-ის გარეშე

თუ ფუნქციას `return` არ აქვს, ის მაინც აბრუნებს მნიშვნელობას, `undefined`-ს. ამიტომ დაიბეჭდა ზემოთ `x`-ის ნაცვლად `undefined`. თუ ეკრანზე მოულოდნელად `undefined` ჩნდება, შეამოწმე, ხომ არ დაგავიწყდა `return`.

## სცადე თავად

გაუშვი, მერე დაამატე ფუნქცია `cube(n)`, რომელიც რიცხვის კუბს აბრუნებს, და დაბეჭდე `cube(3)`.

```js run
function square(n) {
  return n * n;
}

let total = square(3) + square(4);
console.log("3² + 4² =", total);
console.log("ტოლია 5²-ის?", total === square(5));
```

## ხშირი შეცდომები

- **`console.log` `return`-ის ნაცვლად.** ფუნქცია ეკრანზე სწორ პასუხს წერს, მაგრამ `let r = f(2);`-ში `r` არის `undefined`. დაბრუნება `return`-ით.
- **კოდი `return`-ის შემდეგ.** `return x; console.log("მორჩა");` მეორე ხაზი არასოდეს შესრულდება.
- **დაბრუნებული მნიშვნელობის დაკარგვა.** ხაზი `square(5);` ითვლის 25-ს, მაგრამ არსად ინახავს. შედეგი ცვლადში ჩაწერე ან პირდაპირ გამოიყენე.

```js
function toFahrenheit(celsius) {

console.log(toFahrenheit(100));
console.log(toFahrenheit(20));
```

## შეჯამება

- `return` შედეგს აბრუნებს გამოძახების ადგილას. გამოძახება ხდება მნიშვნელობა.
- `console.log` ადამიანს აჩვენებს, `return` პროგრამას აძლევს.
- `return`-ზე ფუნქცია მაშინვე მთავრდება.
- ფუნქცია `return`-ის გარეშე `undefined`-ს აბრუნებს.
