შეამოწმე, რა დაგამახსოვრდა ციკლებზე. თითო კითხვას ერთი სწორი პასუხი აქვს. გასავლელად საჭიროა 70%.

<Quiz>
### რა სამი ნაწილი აქვს ნებისმიერ ციკლს?
- [x] დასაწყისი, პირობა და ბიჯი
- [ ] ცვლადი, ფუნქცია და მასივი
- [ ] if, else და switch
> დასაწყისი ამბობს, საიდან, პირობა, როდემდე, ბიჯი, როგორ ვუახლოვდებით დასასრულს.

### რა იწვევს უსასრულო ციკლს?
- [ ] ძალიან დიდი რიცხვი პირობაში
- [x] პირობა, რომელიც ვერასოდეს ხდება false
- [ ] for-ის გამოყენება while-ის ნაცვლად
> თუ ბიჯი არ არის ან არასწორი მიმართულებით მიდის, პირობა სულ true რჩება.

### რას დაბეჭდავს? `let i = 3; while (i > 0) { console.log(i); i--; }`
- [x] 3, 2, 1
- [ ] 3, 2, 1, 0
- [ ] 2, 1, 0
> როცა i ხდება 0, პირობა `0 > 0` false-ა და ციკლი ჩერდება.

### რამდენჯერ შესრულდება `for (let i = 1; i <= 10; i++)`?
- [ ] 9
- [x] 10
- [ ] 11
> i იღებს მნიშვნელობებს 1-დან 10-ის ჩათვლით.

### რას დაბეჭდავს კოდი? `let s = 0; for (let i = 1; i <= 4; i++) { s += i; } console.log(s);`
- [ ] 4
- [x] 10
- [ ] 1234
> 1 + 2 + 3 + 4 = 10.

### როდის ჯობს `while` for-ს?
- [ ] როცა ზუსტად იცი, რამდენჯერ გაიმეორებ
- [x] როცა გაგრძელება პირობაზეა დამოკიდებული და რაოდენობა წინასწარ არ იცი
- [ ] არასოდეს
> მაგალითად, „სანამ 100 ლარი არ დაგროვდება“.

### რას აკეთებს `continue`?
- [ ] ციკლს წყვეტს
- [x] მიმდინარე იტერაციის დარჩენილ ნაწილს გამოტოვებს
- [ ] პროგრამას აჩერებს
> ციკლი გრძელდება შემდეგი იტერაციით.

### რას დაბეჭდავს? `for (let n = 1; n <= 10; n++) { if (n * n > 20) { console.log(n); break; } }`
- [x] 5
- [ ] 4
- [ ] 5, 6, 7, 8, 9, 10
> 4 * 4 = 16, 5 * 5 = 25 > 20. პირველივე ნაპოვნზე `break` ციკლს წყვეტს.

### გარე ციკლი 5-ჯერ ბრუნავს, შიდა 3-ჯერ. რამდენჯერ შესრულდება შიდა ბლოკი?
- [ ] 8
- [ ] 5
- [x] 15
> 5 × 3 = 15.

### სად უნდა შეიქმნას დამგროვებელი `let sum = 0`?
- [x] ციკლის წინ
- [ ] ციკლის შიგნით
- [ ] ციკლის შემდეგ
> ციკლის შიგნით ის ყოველ იტერაციაზე თავიდან განულდებოდა.
