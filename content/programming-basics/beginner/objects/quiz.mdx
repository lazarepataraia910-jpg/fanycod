შეამოწმე, რა დაგამახსოვრდა ობიექტებზე. თითო კითხვას ერთი სწორი პასუხი აქვს. გასავლელად საჭიროა 70%.

<Quiz>
### რომელი ჩანაწერი ქმნის ობიექტს სწორად?
- [x] { name: "ბიტი", level: 3 }
- [ ] { name = "ბიტი", level = 3 }
- [ ] ["name": "ბიტი", "level": 3]
> ობიექტი ფიგურულ ფრჩხილებშია, გასაღები და მნიშვნელობა ორწერტილით.

### `let p = { x: 5, y: 8 };` რას დაბეჭდავს `console.log(p.y);`?
- [ ] 5
- [x] 8
- [ ] y
> p.y y თვისების მნიშვნელობაა.

### რა მოხდება? `let o = { a: 1 }; o.a = 10;`
- [x] a-ს მნიშვნელობა გახდება 10
- [ ] შეიქმნება მეორე a
- [ ] შეცდომა
> არსებულ თვისებაზე მინიჭება მას ცვლის.

### `let k = "size"; let box = { size: 4 };` რომელი დაბეჭდავს 4-ს?
- [ ] console.log(box.k);
- [x] console.log(box[k]);
- [ ] console.log(box["k"]);
> ცვლადში შენახული გასაღები მხოლოდ კვადრატული ფრჩხილებით მუშაობს.

### რას აკეთებს `delete user.age;`?
- [x] შლის თვისებას age
- [ ] age-ს ანიჭებს 0-ს
- [ ] შლის მთელ ობიექტს
> წაშლის შემდეგ user.age undefined-ია.

### `let list = [{ n: "ა" }, { n: "ბ" }];` რას დაბეჭდავს `console.log(list[0].n);`?
- [x] ა
- [ ] ბ
- [ ] undefined
> list[0] პირველი ობიექტია.

### რას გადის `for...in` ციკლი ობიექტზე?
- [ ] მნიშვნელობებს
- [x] გასაღებებს
- [ ] მხოლოდ რიცხვით თვისებებს
> მნიშვნელობა obj[key]-ით იკითხება.

### რას დააბრუნებს `Object.keys({ a: 1, b: 2, c: 3 }).length`?
- [ ] 6
- [x] 3
- [ ] undefined
> სამი გასაღები: a, b, c.

### რომელი მოდელია უკეთესი წიგნის ჟანრებისთვის?
- [ ] genres: "პოემა, კლასიკა"
- [x] genres: ["პოემა", "კლასიკა"]
- [ ] genre1: "პოემა", genre2: "კლასიკა"
> რაც შეიძლება ბევრი იყოს, მასივში ინახება.

### `let b = { author: { name: "ილია" } };` როგორ წაიკითხო ავტორის სახელი?
- [ ] b.name
- [ ] b.author[name]
- [x] b.author.name
> ჩადგმულ თვისებას წერტილების ჯაჭვით მიწვდები.
