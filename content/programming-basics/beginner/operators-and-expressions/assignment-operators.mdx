## რას ისწავლი

- როგორ შეცვალო ცვლადი მოკლე ჩანაწერით `+=`, `-=`, `*=`, `/=`
- რას აკეთებს `++` და `--`
- როგორ „ააწყო“ ტექსტი თანდათან `+=`-ით

## ცვლადი, რომელიც თავის თავს ცვლის

თამაშებში ერთი და იგივე ცვლადი ხშირად იცვლება: ქულა იზრდება, სიცოცხლე მცირდება. ამის ჩვეულებრივი ჩანაწერი უკვე იცი:

```js
let score = 10;
score = score + 5;
console.log(score);   // 15
```

ეს ხაზი ასე იკითხება: „აიღე `score`-ის ახლანდელი მნიშვნელობა, მიუმატე 5 და შედეგი ისევ `score`-ში ჩადე“. ასეთი რამ იმდენად ხშირია, რომ ენას მისთვის მოკლე ჩანაწერი აქვს.

## მინიჭების მოკლე ოპერატორები

`score = score + 5` და `score += 5` ზუსტად ერთსა და იმავეს ნიშნავს. ასეთი **მინიჭების ოპერატორი (assignment operator)** ყველა არითმეტიკულ მოქმედებას აქვს:

```js
let score = 10;
score += 5;   // score = score + 5  → 15
score -= 3;   // score = score - 3  → 12
score *= 2;   // score = score * 2  → 24
score /= 4;   // score = score / 4  → 6
score %= 4;   // score = score % 4  → 2
console.log(score);
```

მიჰყევი ნაბიჯებს: 10 → 15 → 12 → 24 → 6 → 2. ყოველი ხაზი წინა ხაზის შედეგს იყენებს.

## ერთით გაზრდა და შემცირება

ერთით გაზრდა ყველაზე ხშირი შემთხვევაა: დონე გადავიდა, კიდევ ერთი მონეტა აიღე. ამისთვის ყველაზე მოკლე ჩანაწერი არსებობს:

```js
let level = 1;
level++;      // level = level + 1
console.log(level);   // 2

let lives = 3;
lives--;      // lives = lives - 1
console.log(lives);   // 2
```

`++`-ს **ინკრემენტი (increment)** ჰქვია, `--`-ს **დეკრემენტი (decrement)**. ციკლებში მათ ძალიან ხშირად შეხვდები.

ცვლადს, რომელიც რაღაცას ითვლის, **მთვლელი (counter)** ჰქვია. მთვლელი თითქმის ყველა პროგრამაშია: რამდენჯერ დააჭირა მომხმარებელმა ღილაკს, რამდენი სწორი პასუხი გასცა, რამდენი წამი დარჩა. მისი სიცოცხლე ყოველთვის ერთნაირია: ჯერ იქმნება საწყისი მნიშვნელობით, ხშირად ნულით, მერე პროგრამის განმავლობაში იზრდება ან მცირდება, ბოლოს კი მის მნიშვნელობას ვბეჭდავთ ან ვამოწმებთ.

## ტექსტის აწყობა

`+=` სტრიქონებზეც მუშაობს: ის ტექსტს ბოლოში ამატებს. ასე გრძელ შეტყობინებას ნაწილ-ნაწილ ააწყობ:

```js
let message = "გამარჯობა";
message += ", ნიკა";
message += "!";
console.log(message);   // გამარჯობა, ნიკა!
```

## სცადე თავად

გაუშვი და შეამოწმე, დაემთხვა თუ არა შედეგი შენს ვარაუდს. მერე შეცვალე რიცხვები.

```js run
let coins = 0;
coins += 10;
coins += 10;
coins -= 5;
console.log("მონეტები:", coins);

let level = 1;
level++;
level++;
console.log("დონე:", level);
```

## ხშირი შეცდომები

- **`=+` ნაცვლად `+=`-ისა.** `score =+ 5` შეცდომას არ იძლევა, მაგრამ ნიშნავს `score = +5`-ს: ცვლადს უბრალოდ 5 მიენიჭება. ნიშნების რიგი მნიშვნელოვანია: ჯერ მოქმედება, მერე `=`.
- **`const` ცვლადის შეცვლა.** `const score = 10; score += 5;` შეცდომას იძლევა `TypeError: Assignment to constant variable`. ცვლადი, რომელიც უნდა იცვლებოდეს, `let`-ით შექმენი.
- **გამოსახულება მინიჭების გარეშე.** ხაზი `score + 5;` ითვლის ჯამს, მაგრამ არსად ინახავს. `score` არ იცვლება.

<Exercise>
ყულაბაში 20 ლარია. დაამატე 15 ლარი, მერე დახარჯე 8, ბოლოს ბებიამ რაც დაგრჩა, გაგიორმაგა. ყოველი ნაბიჯი მოკლე ოპერატორით გააკეთე და ბოლოს დაბეჭდე `ყულაბაში: 54`.

```js run
let money = 20;
// სამი ნაბიჯი მოკლე ოპერატორებით
```

<Hint>დამატება `+=`-ით, ხარჯი `-=`-ით, გაორმაგება `*=`-ით. 20 → 35 → 27 → 54.</Hint>

<Solution>
```js
let money = 20;
money += 15;
money -= 8;
money *= 2;
console.log("ყულაბაში:", money);
```
</Solution>

## შეჯამება

- `x += 5` იგივეა, რაც `x = x + 5`. ასევე მუშაობს `-=`, `*=`, `/=` და `%=`.
- `x++` ცვლადს ერთით ზრდის, `x--` ერთით ამცირებს.
- სტრიქონზე `+=` ტექსტს ბოლოში ამატებს.
- ცვლადი, რომელიც იცვლება, `let`-ით უნდა შეიქმნას.
