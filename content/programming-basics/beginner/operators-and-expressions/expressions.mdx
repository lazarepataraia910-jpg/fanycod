## რას ისწავლი

- რა არის გამოსახულება (expression) და რით განსხვავდება ინსტრუქციისგან
- რა რიგით ითვლის კომპიუტერი `+`, `-`, `*` და `/` მოქმედებებს
- როგორ შეცვალო ეს რიგი ფრჩხილებით

## რა არის გამოსახულება

**გამოსახულება (expression)** კოდის ნებისმიერი ნაწილია, რომლის „გამოთვლაც“ შეიძლება და რომელიც ბოლოს ერთ მნიშვნელობას იძლევა. ყველაზე პატარა გამოსახულება ერთი რიცხვი ან ერთი სტრიქონია. უფრო დიდი გამოსახულება პატარებისგან და **ოპერატორებისგან (operator)** შედგება: `+`, `-`, `*`, `/`, `>` და სხვა.

```js
let apples = 5;

console.log(7);            // 7
console.log(3 + 4);        // 7
console.log(apples * 2);   // 10
console.log(apples > 3);   // true
```

ოთხივე `console.log`-ის ფრჩხილებში გამოსახულება წერია. კომპიუტერი ჯერ მას ითვლის და მერე შედეგს ბეჭდავს. ბოლო გამოსახულების შედეგი რიცხვი კი არა, `true`-ა: შედარებაც გამოსახულებაა.

## გამოსახულება და ინსტრუქცია

**ინსტრუქცია (statement)** არის ბრძანება: „შექმენი ცვლადი“, „დაბეჭდე“. გამოსახულება კი მნიშვნელობაა, რომელიც ინსტრუქციის შიგნით გამოიყენება.

```js
let total = 3 * 4 + 2;
```

მთელი ხაზი ინსტრუქციაა: ის ქმნის ცვლადს `total`. ტოლობის ნიშნის მარჯვნივ კი გამოსახულებაა `3 * 4 + 2`. გამოსახულება შეგიძლია ჩასვა ყველგან, სადაც მნიშვნელობაა საჭირო: `=`-ის მარჯვნივ, `console.log`-ის ფრჩხილებში, შაბლონური სტრიქონის `${ }`-ში.

## მოქმედებების რიგი

კომპიუტერი მათემატიკის წესს მიჰყვება: ჯერ გამრავლება და გაყოფა, მერე შეკრება და გამოკლება. ერთნაირი რანგის მოქმედებები მარცხნიდან მარჯვნივ სრულდება.

```js
console.log(2 + 3 * 4);     // 14
console.log((2 + 3) * 4);   // 20
console.log(20 - 8 - 2);    // 10
```

1. პირველ ხაზში ჯერ სრულდება `3 * 4`, ანუ 12, მერე `2 + 12`.
2. მეორე ხაზში ფრჩხილები რიგს ცვლის: ჯერ `2 + 3`, ანუ 5, მერე `5 * 4`.
3. მესამე ხაზში მარცხნიდან ვითვლით: `20 - 8` არის 12, მერე `12 - 2`.

როცა არ ხარ დარწმუნებული, ფრჩხილები ჩასვი. ზედმეტი ფრჩხილი არაფერს აფუჭებს და კოდს უფრო გასაგებს ხდის.

## როგორ ითვლის კომპიუტერი ნაბიჯ-ნაბიჯ

წარმოიდგინე, რომ კომპიუტერი გამოსახულებას თანდათან „ამარტივებს“, სანამ ერთი მნიშვნელობა არ დარჩება:

```js
let price = 3;
let count = 4;
let total = price * count + 2;
// price * count + 2
// 3 * 4 + 2       ← ცვლადების ნაცვლად მნიშვნელობები
// 12 + 2          ← ჯერ გამრავლება
// 14              ← მერე შეკრება
console.log(total);
```

ასე „ხელით“ დათვლა კარგი ჩვევაა: როცა პროგრამა მოულოდნელ პასუხს გაძლევს, ზუსტად ამ გზით იპოვი, სად შეცდა.

## სცადე თავად

გაუშვი, მერე ფრჩხილები სხვა ადგილას გადაიტანე და ნახე, როგორ იცვლება პასუხი.

```js run
let a = 6;
let b = 4;

console.log(a + b * 2);
console.log((a + b) * 2);
console.log(a + b / 2);
console.log((a + b) / 2);
```

## ხშირი შეცდომები

- **საშუალოს დათვლა ფრჩხილების გარეშე.** `a + b / 2` ჯერ ყოფს `b`-ს და მერე უმატებს `a`-ს. ორი რიცხვის საშუალოა `(a + b) / 2`.
- **მათემატიკური ჩანაწერი.** რვეულში `2x` ნიშნავს „2-ჯერ x“, კოდში კი გამრავლება ყოველთვის `*`-ით იწერება: `2 * x`. ნიშნები `×` და `÷` კოდში არ მუშაობს.
- **მძიმე ათწილადში.** `3,5` კოდში ორი ცალკე რიცხვია. ათწილადი წერტილით იწერება: `3.5`.

მართკუთხედის სიგანეა 7, სიმაღლე 3. შექმენი ორი ცვლადი და დაბეჭდე ფართობი (სიგანე გამრავლებული სიმაღლეზე) და პერიმეტრი (ორჯერ სიგანისა და სიმაღლის ჯამი). უნდა დაიბეჭდოს `ფართობი: 21` და `პერიმეტრი: 20`.

```js run
// სიგანე, სიმაღლე, ფართობი და პერიმეტრი
```

<Hint>პერიმეტრში ფრჩხილები გჭირდება: `2 * (width + height)`. მათ გარეშე ჯერ `2 * width` გამოითვლება.</Hint>

<Solution>
```js
let width = 7;
let height = 3;

console.log("ფართობი:", width * height);
console.log("პერიმეტრი:", 2 * (width + height));
```
</Solution>

## შეჯამება

- გამოსახულება კოდის ნაწილია, რომელიც ერთ მნიშვნელობას იძლევა: რიცხვს, ტექსტს ან `true`/`false`-ს.
- ჯერ სრულდება `*` და `/`, მერე `+` და `-`. ერთნაირი რანგის მოქმედებები მარცხნიდან მარჯვნივ.
- ფრჩხილები რიგს ცვლის და კოდს უფრო გასაგებს ხდის.
- მოულოდნელ პასუხს იპოვი, თუ გამოსახულებას ნაბიჯ-ნაბიჯ „ხელით“ დაითვლი.
