## რას ისწავლი

- რა არის ლოგიკური მნიშვნელობა (boolean) და რატომ აქვს მას მხოლოდ ორი ვარიანტი
- როგორ შეადარო ორი მნიშვნელობა შედარების ოპერატორებით
- რით განსხვავდება `=` და `===`

## კი ან არა

ბევრ კითხვას მხოლოდ ორი პასუხი აქვს: „წვიმს?“, „შუქი ანთია?“, „მოთამაშემ მოიგო?“. პასუხია „კი“ ან „არა“, სხვა ვარიანტი არ არსებობს.

პროგრამირებაში ასეთ პასუხს **ლოგიკური მნიშვნელობა (boolean)** ჰქვია. მას მხოლოდ ორი შესაძლო მნიშვნელობა აქვს: `true` (ჭეშმარიტი) და `false` (მცდარი). ორივე ბრჭყალების გარეშე იწერება, პატარა ასოებით.

```js
let isRaining = true;
let hasUmbrella = false;
console.log(isRaining, hasUmbrella);
```

ლოგიკური მნიშვნელობა შუქის ჩამრთველს ჰგავს: ან ჩართულია, ან გამორთული. რიცხვს და სტრიქონს უამრავი შესაძლო მნიშვნელობა აქვს, ლოგიკურს კი მხოლოდ ორი.

## შედარება ლოგიკურ მნიშვნელობას იძლევა

`true`-ს და `false`-ს ხელით იშვიათად წერ. უფრო ხშირად მათ კომპიუტერი გიბრუნებს, როცა ორ მნიშვნელობას ადარებ **შედარების ოპერატორით (comparison operator)**:

| ოპერატორი | კითხვა | მაგალითი | შედეგი |
|---|---|---|---|
| `>` | მეტია? | `8 > 5` | `true` |
| `<` | ნაკლებია? | `8 < 5` | `false` |
| `>=` | მეტია ან ტოლი? | `5 >= 5` | `true` |
| `<=` | ნაკლებია ან ტოლი? | `4 <= 3` | `false` |
| `===` | ტოლია? | `7 === 7` | `true` |
| `!==` | განსხვავდება? | `7 !== 7` | `false` |

ყოველი შედარება კითხვაა, რომელზეც კომპიუტერი `true`-თი ან `false`-ით პასუხობს.

```js
let age = 12;
console.log(age > 10);
console.log(age === 18);
console.log(age !== 18);
```

1. `age > 10` კითხულობს: „12 მეტია 10-ზე?“. პასუხია `true`.
2. `age === 18` კითხულობს: „12 ტოლია 18-ის?“. პასუხია `false`.
3. `age !== 18` კითხულობს: „12 განსხვავდება 18-ისგან?“. პასუხია `true`.

## პასუხის შენახვა ცვლადში

შედარების შედეგი ჩვეულებრივი მნიშვნელობაა, ამიტომ მისი ცვლადში შენახვა შეიძლება. ასეთ ცვლადს ხშირად კითხვის მსგავს სახელს არქმევენ, რომელიც `is`-ით ან `has`-ით იწყება.

```js
let score = 85;
let hasPassed = score >= 50;
console.log("ჩააბარა?", hasPassed);
```

1. კომპიუტერი ჯერ ითვლის მარჯვენა მხარეს: `85 >= 50` არის `true`.
2. `true` ინახება ცვლადში `hasPassed`.
3. იბეჭდება `ჩააბარა? true`.

სტრიქონების შედარებაც შეიძლება: `"კატა" === "კატა"` არის `true`, `"კატა" === "ძაღლი"` კი `false`.

## სცადე თავად

გაუშვი. მერე შეცვალე `score` 30-ით და ნახე, როგორ შეიცვლება პასუხები. დაამატე ხაზი, რომელიც შეამოწმებს, არის თუ არა ქულა ზუსტად 100.

```js run
let score = 85;
let hasPassed = score >= 50;

console.log("ჩააბარა?", hasPassed);
console.log("90-ზე მეტია?", score > 90);
```

## ხშირი შეცდომები

- **`=` შედარების ნაცვლად.** `score = 100` არაფერს ადარებს: ის ქულას 100-ად აქცევს. შესადარებლად გჭირდება სამი ტოლობის ნიშანი: `score === 100`.
- **`true` ბრჭყალებში.** `"true"` სტრიქონია, ოთხი ასოსგან შემდგარი ტექსტი, და არა ლოგიკური მნიშვნელობა. დაწერე `true` ბრჭყალების გარეშე.
- **ნიშნების რიგის არევა.** „მეტია ან ტოლი“ იწერება `>=`, და არა `=>`. ჯერ შედარების ნიშანი, მერე ტოლობა.
- **რიცხვისა და სტრიქონის შედარება.** `5 === "5"` არის `false`: ერთი რიცხვია, მეორე ტექსტი. `===` ამოწმებს, რომ მნიშვნელობაც და ტიპიც ემთხვეოდეს.

## შეჯამება

- ლოგიკურ მნიშვნელობას ორი ვარიანტი აქვს: `true` და `false`.
- შედარების ოპერატორები (`>`, `<`, `>=`, `<=`, `===`, `!==`) ლოგიკურ მნიშვნელობას აბრუნებს.
- `=` მინიჭებაა, `===` შედარება.
- შედარების შედეგი შეგიძლია ცვლადში შეინახო. პირობებში (`if`) სწორედ ასეთ მნიშვნელობებს გამოიყენებ.
