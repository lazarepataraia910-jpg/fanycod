## რას ისწავლი

- რა არის მუდმივა (constant) და რით განსხვავდება `const` სიტყვისგან `let`
- რა წესებს უნდა აკმაყოფილებდეს ცვლადის სახელი
- როგორ აირჩიო სახელი, რომელსაც ერთი თვის შემდეგაც გაიგებ

## მნიშვნელობა, რომელიც არ იცვლება

ზოგი რამ პროგრამის მუშაობისას იცვლება: ქულა, დარჩენილი სიცოცხლეები, კალათის ჯამი. ზოგი კი არასდროს: კვირაში დღეების რაოდენობა, თამაშის სახელი, მაქსიმალური ქულა.

ასეთი მნიშვნელობისთვის `let`-ის ნაცვლად იყენებ სიტყვას `const`. ის ქმნის **მუდმივას (constant)**: ყუთს, რომელიც მნიშვნელობის ჩადების შემდეგ ილუქება.

```js
const DAYS_IN_WEEK = 7;
const gameTitle = "კოსმოსური რბოლა";

console.log(gameTitle, "გრძელდება", DAYS_IN_WEEK, "დღე");
```

1. `const` ქმნის მუდმივას და მაშინვე ანიჭებს მნიშვნელობას.
2. შემდეგ მას ჩვეულებრივი ცვლადივით იყენებ: სახელს წერ და კომპიუტერი მნიშვნელობას სვამს.

## რა ხდება, თუ მუდმივას შეცვლი

```js
const maxScore = 100;
maxScore = 200;
```

მეორე ხაზზე პროგრამა ჩერდება და გიჩვენებს: `TypeError: Assignment to constant variable.`, ანუ „მუდმივას მინიჭება არ შეიძლება“. ეს შეცდომა სასარგებლოა: კომპიუტერი გიცავს იმისგან, რომ შემთხვევით შეცვალო ის, რაც არ უნდა შეიცვალოს.

მარტივი წესი: **ყოველთვის დაიწყე `const`-ით**. `let` გამოიყენე მხოლოდ მაშინ, როცა იცი, რომ მნიშვნელობა შეიცვლება. ასე კოდის მკითხველი ერთი შეხედვით ხვდება, რა იცვლება პროგრამაში და რა არა.

## სახელის წესები

ცვლადისა და მუდმივას სახელს კომპიუტერი რამდენიმე წესს უყენებს:

- სახელი შედგება ასოების, ციფრების და ქვედა ტირისგან `_`. ინტერვალი და ტირე `-` არ შეიძლება.
- სახელი ციფრით ვერ დაიწყება: `player1` სწორია, `1player` არა.
- დიდი და პატარა ასო განსხვავდება: `score` და `Score` ორი სხვადასხვა ცვლადია.
- ენის საკუთარი სიტყვები დაკავებულია: ცვლადს ვერ დაარქმევ `let`, `const` ან `true`.

## კარგი სახელი

წესების დაცვა საკმარისი არ არის. `x`, `a1` და `data` კომპიუტერისთვის მისაღებია, ადამიანისთვის კი არაფერს ამბობს. კარგი სახელი პასუხობს კითხვას: **რა ინახება შიგნით?**

```js
const p = 3;
const t = 25;
console.log(p * t);

const ticketPrice = 3;
const studentCount = 25;
console.log(ticketPrice * studentCount);
```

1. პირველი სამი ხაზი მუშაობს, მაგრამ ვერ მიხვდები, რას ითვლის.
2. ბოლო სამი ხაზი იმავეს აკეთებს და თავად ხსნის თავს: ბილეთის ფასი გამრავლებული მოსწავლეების რაოდენობაზე.

რამდენიმე სიტყვისგან შემდგარ სახელს JavaScript-ში ასე წერენ: პირველი სიტყვა პატარა ასოთი, ყოველი შემდეგი დიდით, ინტერვალის გარეშე. ამ სტილს **camelCase** ჰქვია, რადგან დიდი ასოები აქლემის კუზებს ჰგავს: `ticketPrice`, `studentCount`, `isGameOver`. სახელებს ინგლისურად ვწერთ, რადგან ასეა მიღებული მთელ მსოფლიოში.

მუდმივებს, რომელთა მნიშვნელობა წინასწარ არის ცნობილი და არასდროს იცვლება, ხშირად დიდი ასოებით და ქვედა ტირეებით წერენ: `DAYS_IN_WEEK`, `MAX_SCORE`.

## სცადე თავად

გაუშვი და ნახე შეცდომა. მერე გაასწორე პროგრამა ისე, რომ იმუშაოს: რომელი სიტყვა უნდა შეცვალო პირველ ხაზში?

```js run
const lives = 3;
console.log("სიცოცხლეები:", lives);

lives = 2;
console.log("სიცოცხლეები:", lives);
```

## ხშირი შეცდომები

- **`const` იმაზე, რაც იცვლება.** თუ მნიშვნელობას მოგვიანებით ახალს ანიჭებ, გჭირდება `let`. `const`-ზე მინიჭება `TypeError`-ს იძლევა.
- **`const` მნიშვნელობის გარეშე.** `const total;` შეცდომაა: მუდმივას მნიშვნელობა შექმნისთანავე უნდა მიენიჭოს.
- **ინტერვალი ან ტირე სახელში.** `ticket price` და `ticket-price` არ მუშაობს. დაწერე `ticketPrice`.
- **ასოების რეგისტრის არევა.** თუ შექმენი `studentCount` და მერე წერ `studentcount`, კომპიუტერი მეორეს ვერ იპოვის.

```js run
let a = 3.14;
let b = 5;
let c = a * b * b;
console.log(c);
```

<Solution>
```js
const PI = 3.14;
const radius = 5;
const area = PI * radius * radius;

console.log("წრის ფართობი:", area);
```
</Solution>

## შეჯამება

- `const` ქმნის მუდმივას: მნიშვნელობას, რომელიც აღარ იცვლება. `let` გამოიყენე მხოლოდ იმისთვის, რაც იცვლება.
- სახელი შედგება ასოების, ციფრების და `_`-ისგან, ციფრით არ იწყება და რეგისტრს განასხვავებს.
- კარგი სახელი ამბობს, რა ინახება შიგნით: `ticketPrice`, არა `p`.
- რამდენიმე სიტყვა camelCase სტილით იწერება.
