## რას ისწავლი

- რა არითმეტიკული ოპერატორები (operator) აქვს JavaScript-ს
- რა რიგით სრულდება მოქმედებები და როგორ ცვლის ამ რიგს ფრჩხილები
- როგორ გამოთვალო ცვლადებით და შეინახო შედეგი ახალ ცვლადში

## რიცხვი პროგრამაში

რიცხვი (number) ბრჭყალების გარეშე იწერება: `7`, `120`, `-3`. ათწილადში მძიმის ნაცვლად **წერტილი** იწერება: `2.5`, `19.99`.

მოქმედების ნიშანს პროგრამირებაში **ოპერატორი (operator)** ჰქვია. აი ხუთი ოპერატორი, რომელიც ყველაზე ხშირად გამოგადგება:

| ოპერატორი | მოქმედება | მაგალითი | შედეგი |
|---|---|---|---|
| `+` | შეკრება | `7 + 3` | `10` |
| `-` | გამოკლება | `7 - 3` | `4` |
| `*` | გამრავლება | `7 * 3` | `21` |
| `/` | გაყოფა | `7 / 2` | `3.5` |
| `%` | ნაშთი | `7 % 3` | `1` |

ბოლო ოპერატორი ახალია. `%` გაყოფის შედეგს კი არა, **ნაშთს** აბრუნებს: 7 კანფეტი სამ ბავშვს რომ თანაბრად გაუყო, თითოს 2 შეხვდება და 1 დაგრჩება. ეს 1 არის `7 % 3`.

## მოქმედებათა რიგი

კომპიუტერი მათემატიკის წესებს იცავს: ჯერ გამრავლება, გაყოფა და ნაშთი, მერე შეკრება და გამოკლება. რიგის შესაცვლელად ფრჩხილებს იყენებ.

```js
console.log(2 + 3 * 4);
console.log((2 + 3) * 4);
```

1. პირველ ხაზში ჯერ სრულდება `3 * 4`, ანუ 12, მერე ემატება 2. შედეგია `14`.
2. მეორე ხაზში ფრჩხილები აიძულებს კომპიუტერს, ჯერ `2 + 3` გამოთვალოს. შედეგია `5 * 4`, ანუ `20`.

თუ არ ხარ დარწმუნებული რიგში, დასვი ფრჩხილები. ზედმეტი ფრჩხილი არაფერს აფუჭებს, კოდი კი უფრო გასაგები ხდება.

## გამოთვლები ცვლადებით

რიცხვის ნაცვლად გამოსახულებაში ცვლადის ჩაწერაც შეიძლება. კომპიუტერი სახელის ადგილას მის მნიშვნელობას ჩასვამს.

```js
let price = 4;
let count = 3;
let total = price * count;

console.log("სულ გადასახდელია:", total);
```

1. პირველი ორი ხაზი ქმნის ცვლადებს: ერთი ნივთის ფასი და რაოდენობა.
2. მესამე ხაზში კომპიუტერი ჯერ ითვლის მარჯვენა მხარეს (`4 * 3`), მერე შედეგს, `12`-ს, ინახავს ახალ ცვლადში `total`.
3. ბოლო ხაზი ბეჭდავს ტექსტს და `total`-ის მნიშვნელობას.

თუ ფასი შეიცვლება, მხოლოდ პირველ ხაზს შეასწორებ და მთელი გამოთვლა თავისით განახლდება. აი რატომ ჯობია ცვლადები პირდაპირ ჩაწერილ რიცხვებს.

## სცადე თავად

გაუშვი. მერე შეცვალე `price` და `count` და ნახე, როგორ იცვლება შედეგი. ბოლოს დაამატე ხაზი, რომელიც დაბეჭდავს `total % 5`-ს.

```js run
let price = 4;
let count = 3;
let total = price * count;

console.log("სულ გადასახდელია:", total);
console.log("ნახევარი:", total / 2);
```

## ხშირი შეცდომები

- **მძიმე ათწილადში.** `2,5` პროგრამისთვის ათწილადი არ არის. დაწერე `2.5`.
- **რიცხვი ბრჭყალებში.** `"4" + 3` შვიდს კი არა, `43`-ს იძლევა: ბრჭყალებში ჩაწერილი რიცხვი ტექსტია. რიცხვი, რომლითაც ითვლი, ბრჭყალების გარეშე დაწერე. ამაზე შემდეგ თავში ვილაპარაკებთ.
- **რიგის დავიწყება.** საშუალოს გამოსათვლელად `10 + 20 / 2` არასწორია: ჯერ გაყოფა შესრულდება და მიიღებ `20`-ს. სწორია `(10 + 20) / 2`.
- **გაკვირვება ათწილადებზე.** `0.1 + 0.2` კომპიუტერში `0.30000000000000004` გამოდის. ეს შენი შეცდომა არ არის: კომპიუტერი ათწილადებს მიახლოებით ინახავს.

<Exercise>
სამი წიგნი ღირს 12, 8.5 და 15 ლარი. შექმენი სამი ცვლადი ფასებით, გამოთვალე ჯამი ცვლადში `total` და საშუალო ფასი ცვლადში `average`. დაბეჭდე ორივე.

```js run
// სამი ფასი, ჯამი და საშუალო
```

<Hint>საშუალო ჯამის სამზე გაყოფაა: `let average = total / 3;`. თუ ჯამს ცვლადში არ ინახავ, ფრჩხილები არ დაგავიწყდეს.</Hint>

<Solution>
```js
let book1 = 12;
let book2 = 8.5;
let book3 = 15;

let total = book1 + book2 + book3;
let average = total / 3;

console.log("ჯამი:", total);
console.log("საშუალო:", average);
```
</Solution>

## შეჯამება

- რიცხვი ბრჭყალების გარეშე იწერება, ათწილადი წერტილით.
- ოპერატორებია `+`, `-`, `*`, `/` და `%` (ნაშთი).
- ჯერ სრულდება `*`, `/`, `%`, მერე `+` და `-`. რიგს ფრჩხილები ცვლის.
- გამოთვლის შედეგი შეგიძლია ახალ ცვლადში შეინახო.
