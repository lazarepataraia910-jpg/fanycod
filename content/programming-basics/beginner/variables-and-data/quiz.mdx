შეამოწმე, რა დაგამახსოვრდა ცვლადებსა და მონაცემებზე. თითო კითხვას ერთი სწორი პასუხი აქვს. გასავლელად საჭიროა 70%.

<Quiz>
### რა არის ცვლადი?
- [x] სახელიანი ადგილი მეხსიერებაში, რომელიც მნიშვნელობას ინახავს
- [ ] ბრძანება, რომელიც ეკრანზე ბეჭდავს
- [ ] შეცდომის სახეობა
> ცვლადი სახელიან ყუთს ჰგავს: მასში მნიშვნელობას დებ და მოგვიანებით სახელით კითხულობ.

### რას დაბეჭდავს ეს კოდი? `let a = 3; a = a + 2; console.log(a);`
- [ ] 3
- [ ] a + 2
- [x] 5
> კომპიუტერი ჯერ ითვლის მარჯვენა მხარეს (3 + 2) და შედეგს იმავე ცვლადში ინახავს.

### რას უდრის `2 + 6 / 2`?
- [ ] 4
- [x] 5
- [ ] 8
> ჯერ სრულდება გაყოფა: 6 / 2 არის 3. მერე 2 + 3, ანუ 5.

### რას უდრის `20 % 6`?
- [x] 2
- [ ] 3
- [ ] 3.33
> `%` ნაშთს აბრუნებს. 20-ში 6 სამჯერ ეტევა (18) და რჩება 2.

### რას დაბეჭდავს `console.log("10" + 5);`?
- [ ] 15
- [x] 105
- [ ] შეცდომას
> "10" სტრიქონია, ამიტომ `+` აერთებს და არ კრებს.

### რომელი ხაზი დაბეჭდავს „გამარჯობა, ანა!“-ს, თუ `let name = "ანა";`?
- [ ] console.log("გამარჯობა, name!");
- [ ] console.log("გამარჯობა, ${name}!");
- [x] console.log("გამარჯობა, " + name + "!");
> ჩვეულებრივ ბრჭყალებში name უბრალოდ სიტყვაა და `${ }` არ მუშაობს. შეერთება `+`-ით ცვლადის მნიშვნელობას სვამს.

### რას დაბეჭდავს `console.log(4 === 4);`?
- [x] true
- [ ] false
- [ ] 4
> `===` ადარებს ორ მნიშვნელობას. ისინი ტოლია, ამიტომ პასუხია true.

### რა ინახება ცვლადში `let isTall = 120 >= 150;`?
- [ ] 120
- [ ] true
- [x] false
> 120 არც მეტია 150-ზე და არც ტოლი, ამიტომ შედარების შედეგია false.

### როდის უნდა გამოიყენო `let` და არა `const`?
- [ ] ყოველთვის
- [x] როცა მნიშვნელობა მოგვიანებით შეიცვლება
- [ ] როცა მნიშვნელობა ტექსტია
> ნაგულისხმევად `const` გამოიყენე. `let` საჭიროა მხოლოდ იმ ცვლადისთვის, რომელსაც ახალ მნიშვნელობას მიანიჭებ.

### რომელი სახელია ყველაზე კარგი მოთამაშის ქულისთვის?
- [ ] s
- [ ] player score
- [x] playerScore
> სახელი უნდა ამბობდეს, რა ინახება შიგნით, და ინტერვალს არ შეიცავდეს. `playerScore` camelCase სტილითაა.
