## რას ისწავლი

- რა არის სტრიქონი (string) და როგორ იწერება
- როგორ შეაერთო სტრიქონები და ჩასვა ტექსტში ცვლადი
- როგორ გაიგო სტრიქონის სიგრძე და რატომ იძლევა `"5" + 3` ორმოცდაცამეტს

## რა არის სტრიქონი

ტექსტს პროგრამირებაში **სტრიქონი (string)** ჰქვია: ეს სიმბოლოების რიგია, ერთმანეთზე ასხმული, როგორც მძივები ძაფზე. სტრიქონია სახელი, წინადადება, ტელეფონის ნომერი, ერთი ასოც კი.

სტრიქონი ყოველთვის ბრჭყალებში იწერება. JavaScript-ში ორმაგი და ერთმაგი ბრჭყალი ერთნაირად მუშაობს, მთავარია, დასაწყისსა და ბოლოში ერთნაირი იყოს:

```js
let greeting = "გამარჯობა";
let name = 'ნიკა';
console.log(greeting, name);
```

ამ კურსში ძირითადად ორმაგ ბრჭყალებს ვიყენებთ.

## სტრიქონების შეერთება

ნიშანი `+` რიცხვებს კრებს, სტრიქონებს კი **აერთებს**: ერთს მეორის ბოლოში აწებებს. ამას **შეერთება (concatenation)** ჰქვია.

```js
let firstName = "ნიკა";
let message = "გამარჯობა, " + firstName + "!";
console.log(message);
```

1. პირველი ხაზი ინახავს სახელს.
2. მეორე ხაზი სამ ნაწილს აერთებს: ტექსტს `"გამარჯობა, "`, ცვლადის მნიშვნელობას და ძახილის ნიშანს.
3. იბეჭდება `გამარჯობა, ნიკა!`.

ყურადღება მიაქციე ინტერვალს მძიმის შემდეგ, ბრჭყალების შიგნით. კომპიუტერი ინტერვალს თვითონ არ ამატებს: `"გამარჯობა," + firstName` დაბეჭდავდა `გამარჯობა,ნიკა`-ს.

## ცვლადის ჩასმა ტექსტში

როცა ბევრი ნაწილია, პლუსები და ბრჭყალები ადვილად ირევა. ამისთვის არსებობს უფრო მოსახერხებელი ჩანაწერი, **შაბლონური სტრიქონი (template literal)**. ის ჩვეულებრივი ბრჭყალების ნაცვლად უკუბრჭყალებში იწერება (კლავიატურაზე Esc-ის ქვეშ), ცვლადი კი პირდაპირ ტექსტში ისმება `${ }`-ის შიგნით.

```js
let firstName = "ნიკა";
let age = 12;
console.log(`მე ვარ ${firstName} და ვარ ${age} წლის.`);
console.log(`ათ წელიწადში ვიქნები ${age + 10} წლის.`);
```

1. პირველ `console.log`-ში კომპიუტერი `${firstName}`-ის და `${age}`-ის ადგილას ცვლადების მნიშვნელობებს სვამს.
2. მეორეში `${ }`-ის შიგნით გამოთვლაა. კომპიუტერი ჯერ ითვლის `age + 10`-ს და შედეგს სვამს.

## სტრიქონის სიგრძე

ყოველმა სტრიქონმა „იცის“, რამდენი სიმბოლოსგან შედგება. ამის გასაგებად სახელის შემდეგ დაწერე `.length`:

```js
let word = "პროგრამა";
console.log(word.length);
```

იბეჭდება `8`. ინტერვალიც და სასვენი ნიშანიც სიმბოლოდ ითვლება.

## სცადე თავად

გაუშვი. მერე შეცვალე ცვლადები შენი მონაცემებით და დაამატე ხაზი, რომელიც `firstName`-ის სიგრძეს დაბეჭდავს.

```js run
let firstName = "ნიკა";
let age = 12;

console.log("გამარჯობა, " + firstName + "!");
console.log(`მე ვარ ${firstName} და ვარ ${age} წლის.`);
```

## ხშირი შეცდომები

- **`"5" + 3` არ არის 8.** თუ `+`-ის ერთ-ერთი მხარე სტრიქონია, კომპიუტერი აერთებს და არ კრებს: შედეგია სტრიქონი `"53"`. რიცხვებს ბრჭყალების გარეშე წერე.
- **დავიწყებული ინტერვალი.** `"ქულა:" + 10` იძლევა `ქულა:10`-ს. ინტერვალი ბრჭყალების შიგნით ჩაწერე: `"ქულა: " + 10`.
- **`${ }` ჩვეულებრივ ბრჭყალებში.** `"გამარჯობა, ${firstName}"` ცვლადს არ ჩასვამს და ყველაფერს სიტყვასიტყვით დაბეჭდავს. ჩასმა მხოლოდ უკუბრჭყალებში მუშაობს.
- **სხვადასხვა ბრჭყალი დასაწყისსა და ბოლოში.** `"ნიკა'` შეცდომაა: სტრიქონი იმავე ბრჭყალით უნდა დაიხუროს, რომლითაც გაიხსნა.

```js run
// ორი ცვლადი, წინადადება და სიგრძე
```

<Hint>წინადადება უკუბრჭყალებში ჩაწერე და ცვლადები ჩასვი `${animal}` და `${legs}` სახით. სიგრძეა `animal.length`.</Hint>

<Solution>

```js
let animal = "კატა";

```

## შეჯამება

- სტრიქონი ტექსტია და ყოველთვის ბრჭყალებში იწერება.
- `+` სტრიქონებს აერთებს. ინტერვალი თვითონ უნდა ჩაწერო.
- უკუბრჭყალებში `${ }`-ით ტექსტში ცვლადს ან გამოთვლას ჩასვამ.
- `.length` სტრიქონის სიმბოლოების რაოდენობას გეუბნება.
