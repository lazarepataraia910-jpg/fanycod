## რას ისწავლი

- რა არის ცვლადი (variable) და რისთვის გვჭირდება
- როგორ შექმნა ცვლადი სიტყვით `let` და მიანიჭო მნიშვნელობა
- როგორ წაიკითხო და შეცვალო ცვლადის მნიშვნელობა

## რატომ გვჭირდება ცვლადი

აქამდე ყველაფერს პირდაპირ ბეჭდავდი. მაგრამ ნამდვილ პროგრამას სჭირდება, რომ რაღაც **დაიმახსოვროს**: მოთამაშის სახელი, დაგროვებული ქულა, კალათაში ჩადებული ნივთის ფასი.

წარმოიდგინე ყუთი, რომელსაც წარწერა აქვს: „ქულა“. ყუთში დებ ფურცელს რიცხვით 10. როცა ქულა დაგჭირდება, ყუთში ჩაიხედავ. როცა ქულა შეიცვლება, ძველ ფურცელს ამოიღებ და ახალს ჩადებ.

**ცვლადი (variable)** სწორედ ასეთი ყუთია კომპიუტერის მეხსიერებაში: მას აქვს **სახელი** და ინახავს **მნიშვნელობას (value)**.

## ცვლადის შექმნა

```js
let score = 10;
console.log(score);
```

1. `let` ნიშნავს: „შექმენი ახალი ცვლადი“.
2. `score` ცვლადის სახელია. სახელს შენ ირჩევ.
3. ნიშანი `=` არის **მინიჭება (assignment)**: „ჩადე მარჯვენა მხარის მნიშვნელობა მარცხენა მხარის ცვლადში“. ის მათემატიკის „უდრის“ არ არის.
4. `10` მნიშვნელობაა, რომელიც ყუთში იდება.
5. მეორე ხაზში `score` ბრჭყალების გარეშე წერია. კომპიუტერი ჩაიხედავს ყუთში და დაბეჭდავს იმას, რაც შიგნით არის: `10`.

ცვლადში ტექსტის შენახვაც შეიძლება. მაშინ მნიშვნელობა ბრჭყალებში იწერება:

```js
let playerName = "ანა";
console.log("მოთამაშე:", playerName);
```

## მნიშვნელობის შეცვლა

ცვლადს იმიტომ ჰქვია ცვლადი, რომ მისი მნიშვნელობა იცვლება. შესაცვლელად `let` აღარ გჭირდება: ყუთი უკვე არსებობს, მხოლოდ ახალ მნიშვნელობას დებ.

```js
let score = 10;
console.log("დასაწყისში:", score);

score = 25;
console.log("ახლა:", score);
```

1. პირველი ხაზი ქმნის ცვლადს მნიშვნელობით `10`.
2. მესამე ინსტრუქცია `score = 25;` ძველ მნიშვნელობას ახლით ცვლის. ძველი `10` აღარ არსებობს.
3. ბოლო ხაზი ბეჭდავს უკვე `25`-ს.

ერთი და იგივე სახელი პროგრამის სხვადასხვა ადგილას სხვადასხვა მნიშვნელობას იძლევა: იმას, რაც იმ მომენტში ყუთში დევს.

## სცადე თავად

გაუშვი. მერე დაამატე ბოლოში კიდევ ერთი ცვლილება: მიანიჭე `score`-ს 100 და დაბეჭდე.

```js run
let playerName = "ანა";
let score = 10;
console.log(playerName, "იწყებს ქულით", score);

score = 25;
console.log("ახლა ქულაა:", score);
```

## ხშირი შეცდომები

- **ცვლადის სახელი ბრჭყალებში.** `console.log("score");` დაბეჭდავს სიტყვას `score` და არა რიცხვს. ცვლადის წასაკითხად სახელი ბრჭყალების გარეშე დაწერე.
- **`let` ორჯერ ერთსა და იმავე სახელზე.** `let score = 10;` და ქვემოთ ისევ `let score = 25;` შეცდომაა (`SyntaxError`): ყუთი ამ სახელით უკვე არსებობს. შესაცვლელად დაწერე უბრალოდ `score = 25;`.
- **ცვლადის გამოყენება შექმნამდე.** თუ `console.log(score);` წერია ხაზზე, რომელიც `let score`-ს უსწრებს, კომპიუტერი შეცდომას გიჩვენებს: ყუთი ჯერ არ არსებობს.
- **`=` წაკითხვა, როგორც „უდრის“.** `score = 25` არ ამოწმებს, უდრის თუ არა ქულა 25-ს. ის ქულას 25-ად აქცევს.

## შეჯამება

- ცვლადი სახელიანი ყუთია, რომელიც მნიშვნელობას ინახავს.
- `let score = 10;` ქმნის ცვლადს; `score = 25;` ცვლის მის მნიშვნელობას.
- `=` მინიჭებაა: მარჯვენა მხარის მნიშვნელობა იდება მარცხენა მხარის ცვლადში.
- ცვლადის წასაკითხად სახელი ბრჭყალების გარეშე იწერება.
