## რას ისწავლი

- რატომ ასრულებს კომპიუტერი ზუსტად იმას, რაც დაწერე, და არა იმას, რაც იგულისხმე
- რით განსხვავდება ტექსტი გამოსათვლელი გამოსახულებისგან
- რატომ არის პროგრამისტის მთავარი უნარი სიზუსტე

## კომპიუტერი ვერ ხვდება

სთხოვე მეგობარს: „ჩაი გამიკეთე“. ის თვითონ მიხვდება, რომ წყალი უნდა აადუღოს, ჭიქა აიღოს და ჩაის პაკეტი ჩადოს. შენ ეს ნაბიჯები არ გითქვამს, მაგრამ მან იცის.

კომპიუტერი ასე ვერ იქცევა. მას არ აქვს გამოცდილება და ვერ ხვდება, რას გულისხმობ. ის ასრულებს **მხოლოდ იმას, რაც წერია**, და **ზუსტად ისე, როგორც წერია**. თუ ნაბიჯს გამოტოვებ, კომპიუტერიც გამოტოვებს. თუ შეცდომით დაწერ, შეცდომითვე შეასრულებს.

სამაგიეროდ კომპიუტერს ორი დიდი უპირატესობა აქვს: ის **ძალიან სწრაფია** (წამში მილიარდობით მარტივ მოქმედებას ასრულებს) და **არ იღლება**. ერთსა და იმავე ინსტრუქციას მილიონჯერ ერთნაირად შეასრულებს.

## რაც დაწერე, იმას იღებ

ნახე ეს პროგრამა. მეორე ხაზში სიტყვა შეცდომით წერია.

```js
console.log("გამარჯობა");
console.log("გამრაჯობა");
```

1. პირველი ხაზი ბეჭდავს სწორ სიტყვას.
2. მეორე ხაზში ასოები არეულია. კომპიუტერი ამას ვერ „გაასწორებს“: ის დაბეჭდავს ზუსტად იმ ასოებს, რომლებიც ბრჭყალებშია.

კომპიუტერისთვის ბრჭყალებში ჩაწერილი ტექსტი უბრალოდ სიმბოლოების რიგია. მან არ იცის, რა არის „სწორი“ სიტყვა.

## ტექსტი თუ გამოთვლა

ახლა ყურადღებით შეადარე ორი ხაზი:

```js
console.log("2 + 2");
console.log(2 + 2);
```

1. პირველ ხაზში `2 + 2` ბრჭყალებშია. კომპიუტერი მას ტექსტად აღიქვამს და უცვლელად ბეჭდავს: `2 + 2`.
2. მეორე ხაზში ბრჭყალები არ არის. კომპიუტერი ხედავს რიცხვებს და შეკრების ნიშანს, ჯერ ითვლის და შედეგს ბეჭდავს: `4`.

განსხვავება მხოლოდ ორი ბრჭყალია, შედეგი კი სრულიად სხვა. აი რატომ არის პროგრამირებაში ყოველი სიმბოლო მნიშვნელოვანი.

## სცადე თავად

გაუშვი, მერე სცადე: მოაშორე ბრჭყალები პირველ ხაზს, ან დაამატე მესამე ხაზი `console.log(10 - 3);`.

```js run
console.log("2 + 2");
console.log(2 + 2);
```

## ხშირი შეცდომები

- **„კომპიუტერი მიხვდება.“** ვერ მიხვდება. თუ პროგრამა არ აკეთებს იმას, რაც გინდოდა, მიზეზი თითქმის ყოველთვის კოდშია და არა კომპიუტერში.
- **ბრჭყალების ზედმეტად ან ნაკლებად დასმა.** `"5 + 5"` ტექსტია, `5 + 5` კი გამოთვლა. სანამ გაუშვებ, იკითხე: ტექსტი მინდა თუ შედეგი?
- **წვრილმანების უგულებელყოფა.** ერთი გამოტოვებული ფრჩხილი ან ზედმეტი ასო საკმარისია, რომ პროგრამა შეცდომით გაჩერდეს. ეს ნორმალურია, ყველა პროგრამისტს ემართება.

## შეჯამება

- კომპიუტერი ასრულებს ზუსტად იმას, რაც დაწერე. ის ვერ ხვდება და ვერ ასწორებს.
- ბრჭყალებში ჩაწერილი ტექსტია და უცვლელად იბეჭდება; ბრჭყალების გარეშე `2 + 2` გამოითვლება.
- პროგრამისტის მთავარი უნარი სიზუსტეა: ყველა ნაბიჯი და ყველა სიმბოლო მნიშვნელოვანია.
- შემდეგ თავში ისწავლი, როგორ დაგეგმო ნაბიჯები კოდის დაწერამდე.
