## რას ისწავლი

- რა არის პროგრამირების ენა (programming language) და სინტაქსი (syntax)
- რატომ არსებობს ბევრი ენა და რისთვის იყენებენ მათ
- რატომ არის მთავარი იდეები ყველა ენაში ერთნაირი

## რატომ გვჭირდება ენა

კომპიუტერის შიგნით მხოლოდ ელექტრული სიგნალებია: არის დენი ან არ არის. ამას ნულებითა და ერთიანებით ჩაწერენ და **მანქანური კოდი (machine code)** ჰქვია. ადამიანისთვის ასეთი ჩანაწერის წერა და წაკითხვა თითქმის შეუძლებელია.

ამიტომ ადამიანებმა მოიგონეს **პროგრამირების ენები (programming language)**. ეს არის წესების ნაკრები, რომლითაც ინსტრუქციებს ადამიანისთვის გასაგები სიტყვებითა და ნიშნებით ვწერთ. მერე სპეციალური პროგრამა ამ ტექსტს კომპიუტერისთვის გასაგებ ფორმაში თარგმნის. შენ წერ `console.log("გამარჯობა");`, თარჯიმანი კი ზრუნავს, რომ კომპიუტერმა ეს შეასრულოს.

ენის წესებს, ანუ იმას, თუ როგორ უნდა ჩაიწეროს ინსტრუქცია, **სინტაქსი (syntax)** ჰქვია. ქართულში წინადადება წერტილით მთავრდება, JavaScript-ში ინსტრუქცია წერტილ-მძიმით. ორივე სინტაქსის წესია.

## ერთი იდეა, სხვადასხვა ჩანაწერი

„გამარჯობა“ ყველა ენაზე სხვანაირად ჟღერს, აზრი კი ერთია. პროგრამირების ენებშიც ასეა. აი ერთი და იგივე ინსტრუქცია სამ ენაზე:

```js
console.log("გამარჯობა, სამყარო!");
```

```python
print("გამარჯობა, სამყარო!")
```

```java
System.out.println("გამარჯობა, სამყარო!");
```

1. პირველი ხაზი JavaScript-ია, შენთვის უკვე ნაცნობი.
2. მეორე Python-ია: ბრძანებას `print` ჰქვია და ბოლოს წერტილ-მძიმე არ სჭირდება.
3. მესამე Java-ა: ბრძანება უფრო გრძელია, მაგრამ იმავეს აკეთებს.

სამივე ეკრანზე ერთსა და იმავე ტექსტს ბეჭდავს. განსხვავდება მხოლოდ სინტაქსი. ამიტომ ვინც ერთი ენა კარგად იცის, მეორეს ბევრად სწრაფად სწავლობს: იდეები იგივეა, იცვლება მხოლოდ ჩანაწერი.

## რომელი ენა რისთვის

ენები სხვადასხვა საქმისთვის შეიქმნა, როგორც ხელსაწყოები: ჩაქუჩი ლურსმნისთვისაა, ხერხი კი ფიცრისთვის.

| ენა | სად იყენებენ ყველაზე ხშირად |
|---|---|
| JavaScript | ვებგვერდები და ვებ-აპლიკაციები |
| Python | მონაცემების ანალიზი, ხელოვნური ინტელექტი, ავტომატიზაცია |
| Java, Kotlin | Android-აპლიკაციები, დიდი კომპანიების სისტემები |
| Swift | iPhone-ის აპლიკაციები |
| C, C++, Rust | თამაშის ძრავები, ოპერაციული სისტემები |
| SQL | მონაცემთა ბაზები |

ამ კურსში ვიყენებთ **JavaScript**-ს. მიზეზი მარტივია: ის პირდაპირ ბრაუზერში ეშვება, ამიტომ არაფრის დაყენება არ გჭირდება. რასაც აქ ისწავლი (ცვლადები, პირობები, ციკლები, ფუნქციები), ყველა სხვა ენაშიც გამოგადგება.

## სცადე თავად

ეს JavaScript-ია. გაუშვი, მერე შეცვალე ტექსტი. ბოლოს სცადე Python-ის ჩანაწერი `print("გამარჯობა")` და ნახე, რას გეტყვის კომპიუტერი.

```js run
console.log("გამარჯობა, სამყარო!");
```

Python-ის ბრძანებაზე შეცდომას მიიღებ: JavaScript-ის თარჯიმანმა არ იცის სიტყვა `print` ამ მნიშვნელობით. ყოველ ენას თავისი სინტაქსი აქვს და მათი არევა არ შეიძლება.

## ხშირი შეცდომები

- **„ჯერ საუკეთესო ენა უნდა ავირჩიო.“** საუკეთესო ენა არ არსებობს, არსებობს ამოცანისთვის შესაფერისი. პირველი ენა ნაკლებად მნიშვნელოვანია, ვიდრე ის, რომ კარგად გაიგო საფუძვლები.
- **„ყველა ენა უნდა ვისწავლო.“** არ არის საჭირო. პროგრამისტების უმეტესობა ყოველდღე ორ-სამ ენას იყენებს.
- **სინტაქსების არევა.** ერთი ენის ბრძანება მეორეში არ მუშაობს. თუ `print`-ს JavaScript-ში დაწერ, პროგრამა ვერ დაბეჭდავს ტექსტს.

## შეჯამება

- პროგრამირების ენა წესების ნაკრებია, რომლითაც ინსტრუქციებს ადამიანისთვის გასაგებად ვწერთ.
- სინტაქსი ენის ჩაწერის წესებია. ყოველ ენას თავისი აქვს.
- ენები სხვადასხვა საქმისთვისაა, მაგრამ მთავარი იდეები ყველგან ერთია.
- ამ კურსში JavaScript-ს ვიყენებთ, რადგან ის ბრაუზერში ეშვება.
