## რას ისწავლი

- რა არის პროგრამა (program) და ინსტრუქცია (instruction)
- რატომ ასრულებს კომპიუტერი ბრძანებებს ზემოდან ქვემოთ, რიგით
- როგორ გამოიყურება და როგორ ეშვება უმარტივესი პროგრამა

## პროგრამა რეცეპტს ჰგავს

წარმოიდგინე, რომ მეგობარს ხაჭაპურის რეცეპტს უწერ: „აიღე ფქვილი. დაამატე წყალი. მოზილე ცომი. ჩადე ყველი. გამოაცხვე.“ ეს ნაბიჯების სიაა. თუ მეგობარი ყველაფერს რიგით გააკეთებს, ხაჭაპური გამოვა.

**პროგრამა (program)** ზუსტად ასეთი სიაა, ოღონდ კომპიუტერისთვის დაწერილი. სიის თითო ნაბიჯს **ინსტრუქცია (instruction)** ჰქვია. ტექსტს, რომლითაც ეს ინსტრუქციები იწერება, **კოდი (code)** ეწოდება, ხოლო ადამიანს, რომელიც კოდს წერს, **პროგრამისტი**.

პროგრამებია თამაში, რომელსაც თამაშობ, ბრაუზერი, რომლითაც ამ გვერდს კითხულობ, და ტელეფონის კალკულატორიც. ყველა მათგანი ინსტრუქციების სიაა, უბრალოდ ძალიან გრძელი.

## კომპიუტერი ინსტრუქციებს რიგით ასრულებს

რეცეპტში ჯერ ცომი უნდა მოზილო და მერე გამოაცხო, პირიქით არ გამოვა. პროგრამაშიც ასეა: კომპიუტერი კოდს კითხულობს **ზემოდან ქვემოთ**, ხაზ-ხაზ. ჯერ ასრულებს პირველ ინსტრუქციას, მერე მეორეს, მერე მესამეს. არცერთს არ ტოვებს და რიგს თვითონ არ ცვლის.

## პირველი პროგრამა

აი პროგრამა სამი ინსტრუქციით. ის დაწერილია ენაზე JavaScript, რომელსაც ამ კურსში გამოვიყენებთ.

```js
console.log("დილა მშვიდობისა!");
console.log("მე პროგრამა ვარ.");
console.log("ნახვამდის!");
```

ხაზ-ხაზ:

1. `console.log("დილა მშვიდობისა!");` ეუბნება კომპიუტერს: „დაბეჭდე ეს ტექსტი ეკრანზე“. დასაბეჭდი ტექსტი ბრჭყალებშია.
2. მეორე ხაზი იმავეს აკეთებს სხვა ტექსტით. ის მხოლოდ პირველის შემდეგ სრულდება.
3. მესამე ხაზი ბოლოს სრულდება. მის შემდეგ ინსტრუქცია აღარ არის, ამიტომ პროგრამა მთავრდება.

`console.log` ჯერ უბრალოდ დაიმახსოვრე, როგორც „დაბეჭდე“. მას დაწვრილებით ამ მოდულის ბოლო თავში განვიხილავთ.

## სცადე თავად

დააჭირე „გაუშვი“-ს და ნახე შედეგი. მერე გადაანაცვლე ხაზები ან შეცვალე ტექსტი ბრჭყალებში და თავიდან გაუშვი.

```js run
console.log("დილა მშვიდობისა!");
console.log("მე პროგრამა ვარ.");
console.log("ნახვამდის!");
```

შენიშნე? რა რიგითაც წერია ხაზები, იმავე რიგით იბეჭდება ტექსტი.

ნუ შეგეშინდება ცდის: კოდის შეცვლით ვერაფერს გააფუჭებ. თუ რამე აირია, დააჭირე „საწყისი კოდი“-ს და ყველაფერი თავიდან დაიწყება. პროგრამირებას სწორედ ასე სწავლობენ: ცვლიან, უშვებენ და აკვირდებიან, რა მოხდა.

## ხშირი შეცდომები

- **ბრჭყალის დავიწყება.** ტექსტი ორივე მხრიდან ბრჭყალებში უნდა იყოს: `"გამარჯობა"`. ერთი ბრჭყალი რომ გამოტოვო, კომპიუტერი ვერ გაიგებს, სად მთავრდება ტექსტი, და შეცდომას გამოიტანს.
- **დიდი და პატარა ასოების არევა.** `console.log` პატარა ასოებით იწერება. `Console.log` ან `console.Log` კომპიუტერისთვის სხვა, უცნობი სიტყვაა.
- **რიგის არევა.** კომპიუტერი ვერ მიხვდება, რომ „ნახვამდის“ ბოლოს უნდა იყოს. ის იმ რიგს მიჰყვება, რომელიც შენ დაწერე.

## შეჯამება

- პროგრამა ინსტრუქციების სიაა, კოდი კი ტექსტი, რომლითაც ეს ინსტრუქციები იწერება.
- კომპიუტერი ინსტრუქციებს ზემოდან ქვემოთ, რიგით ასრულებს.
- `console.log("ტექსტი");` ეკრანზე ტექსტს ბეჭდავს.
- შემდეგ თავში ნახავ, რატომ სჭირდება კომპიუტერს ასეთი ზუსტი მითითებები.
