## რას ისწავლი

- რა არის ალგორითმი (algorithm) და რა სამი თვისება აქვს კარგ ალგორითმს
- როგორ დაშალო ამოცანა პატარა, მკაფიო ნაბიჯებად
- როგორ ჩაწერო გეგმა კოდში კომენტარებით (comment)

## ჯერ გეგმა, მერე კოდი

წინა თავში ნახე, რომ კომპიუტერს ყველა ნაბიჯი ზუსტად უნდა დაუწერო. ამიტომ, სანამ კოდს დაწერ, ჯერ უნდა იცოდე, **რა ნაბიჯებია საჭირო**. ამ ნაბიჯების სიას **ალგორითმი (algorithm)** ჰქვია.

ალგორითმი კოდი არ არის. ეს გეგმაა, რომელიც ჩვეულებრივი ენითაც შეგიძლია ჩაწერო. მაგალითად, ალგორითმი „კბილების გახეხვა“:

1. აიღე ჯაგრისი.
2. დაადე პასტა.
3. იხეხე კბილები ორი წუთი.
4. გამოივლე პირი.
5. გარეცხე ჯაგრისი და დადე ადგილზე.

ყოველდღე ათობით ალგორითმს ასრულებ ისე, რომ არც ფიქრობ: სკოლაში მისვლა, ჩანთის ჩალაგება, ტელეფონზე დარეკვა.

## კარგი ალგორითმის სამი თვისება

- **მკაფიოა.** ყოველი ნაბიჯი ერთნაირად გასაგებია. „ცოტა ხანს იხეხე“ ბუნდოვანია, „იხეხე ორი წუთი“ კი მკაფიო.
- **რიგი სწორია.** პასტას ჯერ ჯაგრისზე ადებ და მერე იხეხავ. ნაბიჯების გადანაცვლება შედეგს აფუჭებს.
- **მთავრდება.** ალგორითმს აქვს ბოლო ნაბიჯი. გეგმა, რომელიც არასდროს სრულდება, ამოცანას ვერ ამოხსნის.

## გეგმა კოდში: კომენტარები

პროგრამისტები გეგმას ხშირად პირდაპირ კოდში წერენ **კომენტარებით (comment)**. კომენტარი ხაზია, რომელიც ორი დახრილი ხაზით `//` იწყება. კომპიუტერი მას საერთოდ არ კითხულობს: კომენტარი ადამიანებისთვისაა.

```js
// 1. მივესალმოთ მომხმარებელს
console.log("გამარჯობა!");

// 2. ვუთხრათ, რას აკეთებს პროგრამა
console.log("მე ვითვლი, რამდენი წუთია დღეში.");

// 3. გამოვთვალოთ და დავბეჭდოთ
console.log(24 * 60);
```

1. ხაზები, რომლებიც `//`-ით იწყება, გეგმის ნაბიჯებია. კომპიუტერი მათ გამოტოვებს.
2. ყოველი კომენტარის ქვეშ წერია ინსტრუქცია, რომელიც ამ ნაბიჯს ასრულებს.
3. `24 * 60` გამოთვლაა: ვარსკვლავი `*` პროგრამირებაში გამრავლების ნიშანია. პროგრამა დაბეჭდავს `1440`-ს.

ასე მუშაობენ გამოცდილი პროგრამისტებიც: ჯერ კომენტარებით წერენ, რა უნდა მოხდეს, და მერე თითო ნაბიჯს კოდით ავსებენ.

## სცადე თავად

გაუშვი პროგრამა. მერე დაამატე მეოთხე ნაბიჯი: კომენტარი `// 4. დავემშვიდობოთ` და მის ქვეშ ინსტრუქცია, რომელიც „ნახვამდის!“-ს დაბეჭდავს.

```js run
// 1. მივესალმოთ მომხმარებელს
console.log("გამარჯობა!");

// 2. ვუთხრათ, რას აკეთებს პროგრამა
console.log("მე ვითვლი, რამდენი წუთია დღეში.");

// 3. გამოვთვალოთ და დავბეჭდოთ
console.log(24 * 60);
```

## ხშირი შეცდომები

- **კოდის წერა გეგმის გარეშე.** დამწყები ხშირად პირდაპირ კოდს იწყებს და შუა გზაზე იკარგება. ორი წუთი გეგმაზე ნახევარ საათს გიზოგავს.
- **ძალიან დიდი ნაბიჯები.** „გააკეთე თამაში“ ნაბიჯი არ არის. თუ ნაბიჯის შესრულება ერთი-ორი ინსტრუქციით ვერ წარმოგიდგენია, დაშალე ის უფრო პატარებად.
- **გამოტოვებული ნაბიჯი.** ადამიანისთვის „თავისთავად ცხადი“ ნაბიჯი კომპიუტერისთვის არ არსებობს, სანამ არ დაწერ.

## შეჯამება

- ალგორითმი ამოცანის ამოხსნის გეგმაა: მკაფიო ნაბიჯები სწორი რიგით, რომლებიც აუცილებლად მთავრდება.
- ჯერ გეგმა, მერე კოდი. დიდი ნაბიჯი დაშალე პატარებად.
- კომენტარი `//`-ით იწყება, კომპიუტერი მას გამოტოვებს. კომენტარებით მოსახერხებელია გეგმის ჩაწერა.
- `*` გამრავლების ნიშანია.
