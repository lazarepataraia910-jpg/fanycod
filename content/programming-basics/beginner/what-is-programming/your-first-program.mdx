## რას ისწავლი

- რისგან შედგება ინსტრუქცია `console.log("...");`
- როგორ დაბეჭდო ტექსტი, რიცხვი და რამდენიმე მნიშვნელობა ერთად
- როგორ გამოიყურება შეცდომა (error) და რატომ არ უნდა შეგეშინდეს მისი

## ერთი ხაზის ანატომია

`console.log` უკვე რამდენჯერმე გამოიყენე. ახლა გავარჩიოთ, რა ნაწილებისგან შედგება ეს ხაზი.

```js
console.log("გამარჯობა!");
```

1. `console` არის **კონსოლი (console)**: ადგილი, სადაც პროგრამა ტექსტს წერს. ამ გვერდზე ეს არის „შედეგის“ ფანჯარა რედაქტორის ქვეშ.
2. წერტილი ნიშნავს „კონსოლის შიგნით იპოვე“.
3. `log` ბრძანებაა: „ჩაწერე“.
4. მრგვალ ფრჩხილებში `( )` წერია ის, რაც უნდა დაიბეჭდოს.
5. ბრჭყალები აჩვენებს, სად იწყება და სად მთავრდება ტექსტი.
6. წერტილ-მძიმე `;` ინსტრუქციის დასასრულია, როგორც წერტილი წინადადების ბოლოს.

ერთად ეს იკითხება ასე: „კონსოლში ჩაწერე ტექსტი გამარჯობა!“.

## ტექსტი, რიცხვი და ორივე ერთად

`console.log`-ს შეუძლია დაბეჭდოს არა მხოლოდ ტექსტი.

```js
console.log("მე 12 წლის ვარ.");
console.log(12);
console.log(12 + 1);
console.log("მომავალ წელს ვიქნები:", 12 + 1);
```

1. პირველი ხაზი ტექსტს ბეჭდავს. ციფრები აქ ტექსტის ნაწილია.
2. მეორე ხაზი რიცხვს ბეჭდავს. რიცხვს ბრჭყალები არ სჭირდება.
3. მესამე ხაზი ჯერ ითვლის და შედეგს, `13`-ს, ბეჭდავს.
4. მეოთხე ხაზში ფრჩხილებში ორი რამ წერია, მძიმით გამოყოფილი. `console.log` ორივეს ერთ ხაზზე დაბეჭდავს, შუაში ინტერვალით: `მომავალ წელს ვიქნები: 13`.

მძიმით შეგიძლია იმდენი მნიშვნელობა ჩამოწერო, რამდენიც გინდა.

## პირველი შეცდომა

ადრე თუ გვიან კოდში რაღაცას არასწორად დაწერ. მაშინ კომპიუტერი ჩერდება და **შეცდომას (error)** გიჩვენებს. ეს არ ნიშნავს, რომ რამე გააფუჭე: შეცდომის შეტყობინება მინიშნებაა, სად უნდა ეძებო.

```js
console.log("ეს ხაზი იმუშავებს.");
consol.log("აქ ასო აკლია.");
console.log("აქამდე პროგრამა ვერ მოვა.");
```

1. პირველი ხაზი ჩვეულებრივ სრულდება.
2. მეორე ხაზში წერია `consol`, ბოლო `e`-ს გარეშე. კომპიუტერმა ასეთი სიტყვა არ იცის და გიჩვენებს შეტყობინებას `ReferenceError: consol is not defined`, ანუ „`consol` არ არის განსაზღვრული“.
3. მესამე ხაზი აღარ სრულდება: შეცდომაზე პროგრამა ჩერდება.

შეტყობინებაში ყოველთვის წერია სიტყვა, რომელიც კომპიუტერმა ვერ გაიგო. იქიდან დაიწყე ძებნა.

## სცადე თავად

გაუშვი პროგრამა და ნახე შეცდომა. მერე გაასწორე მეორე ხაზი და თავიდან გაუშვი: ახლა სამივე ხაზი უნდა დაიბეჭდოს.

```js run
console.log("ეს ხაზი იმუშავებს.");
consol.log("აქ ასო აკლია.");
console.log("აქამდე პროგრამა ვერ მოვა.");
```

## ხშირი შეცდომები

- **გამოტოვებული ფრჩხილი ან ბრჭყალი.** `console.log("გამარჯობა);` ან `console.log("გამარჯობა";` შეცდომას იძლევა `SyntaxError`. ფრჩხილებიც და ბრჭყალებიც წყვილ-წყვილად იხსნება და იხურება.
- **ბრჭყალები რიცხვზე, როცა გამოთვლა გინდა.** `console.log("12 + 1");` დაბეჭდავს ტექსტს `12 + 1` და არა `13`-ს.
- **მძიმის დავიწყება ორ მნიშვნელობას შორის.** `console.log("ასაკი:" 12);` შეცდომაა. მნიშვნელობებს შორის მძიმე უნდა იყოს: `console.log("ასაკი:", 12);`.

## შეჯამება

- `console.log(...)` კონსოლში ბეჭდავს იმას, რაც ფრჩხილებში წერია: ტექსტს, რიცხვს ან გამოთვლის შედეგს.
- რამდენიმე მნიშვნელობა მძიმით გამოიყოფა და ერთ ხაზზე იბეჭდება.
- შეცდომაზე პროგრამა ჩერდება. შეტყობინება გეუბნება, რა ვერ გაიგო კომპიუტერმა.
- მოდული დაასრულე. გაიარე ქვიზი და გადადი ცვლადებზე.
