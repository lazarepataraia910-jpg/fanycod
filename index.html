სად ვისწავლო პროგრამირება ქართულად?

CodeQuest-ზე: სასწავლო თამაშში 19 პროგრამირების ენაა ნულიდან (Python, JavaScript, Node.js, HTML, CSS, Java, C++ და სხვა), ხოლო სკოლაში „ისწავლე კოდინგი“ — 25 კურსი ქართულად, მოკლე თავებით, ცოცხალი კოდითა და ქვიზებით. ყველაფერი ბრაუზერში მუშაობს და დაწყება უფასოა.

რომელი ენით დავიწყო?

სულ ახალბედას — თამაშის ბლოკებით და Python-ით; საიტების შესაქმნელად — HTML, CSS და JavaScript. რა რიგით ისწავლო, გეტყვის სასწავლო გზები.

მართლა უფასოა?

დიახ: ყველა ენის პირველი 100 ლეველი, გარდერობი, მიღწევები და კომპიუტერის ვერსია უფასოა. Pro ხსნის დამატებით ლეველებს, ვიდეოებს, პროექტებს, სკოლას „ისწავლე კოდინგი“, კლასებს და ცოცხალ გაკვეთილებს.

რა ასაკისთვისაა?

დამწყებთათვის: პირველი ლეველები მხოლოდ კითხვის უნარს მოითხოვს, ამიტომ დაწყება დაწყებითი კლასებიდანაც შეიძლება. უფროსები და დიდებიც სწრაფად გადადიან ნამდვილ ენებზე.

რამის დაყენება მჭირდება?

არა, თამაში ბრაუზერში მუშაობს — კომპიუტერზეც და ტელეფონზეც. თუ გინდა, Windows-ზე დააყენე Microsoft Store-იდან (ერთი დაჭერით, თავისით ახლდება), გადმოწერე კომპიუტერის პროგრამა, ან ტელეფონზე დააყენე აპივით.

უსაფრთხოა?
